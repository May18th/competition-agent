## 320-2 轮 · 成功率口径一致性【C】

### 现象 / 结论
- 结论：**成功率 = 成功 / (成功 + 未处理失败)**；当前未处理失败 = 0，所以 100.0% 是**真实口径**，数字本身没错。
- 矛盾点：「最近失败」里显示着 09-27 的英文报错（该条**已处理 / 已关闭**），但成功率仍显示 100% —— 因为「最近失败」列表**没有按状态过滤**，导致页面上「有失败记录」和「成功率 100%」看起来自相矛盾。

### 要求
1. **「最近失败」标注状态**（已处理 / 已关闭 / 未处理），或**默认只显示未处理失败**（二选一，请 C 定并在回执说明）。
2. **成功率 / 失败率口径说明**加在页面上（或 tooltip），让用户知道分母只包含未处理失败。
3. 保证「最近失败」与成功率显示**不自相矛盾**。

### 验收
- 「最近失败」与成功率同时看，逻辑不冲突（要么列表只剩未处理失败，要么每条都带状态标注）。
- 页面上有口径说明（可见文案或 tooltip）。
- 桌面端 + 移动端一致。

### 归属
- C：全量（列表过滤/状态标注、口径说明文案）。

### 备注
- 若选「默认只显示未处理失败」，建议再给一个「显示全部」开关，方便排查历史问题 —— 是否加由 C 定。
- 本轮与 316 轮（失败提示友好中文）、320 轮（失败记录按时间段过滤）会同时作用在「最近失败」这一块，**建议一并处理，避免改三次互相覆盖**。
