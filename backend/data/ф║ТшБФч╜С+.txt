# 中国国际 "互联网 +" 大学生创新创业大赛
> 来源：全国大学生创业服务网 cy.ncss.cn《中国国际大学生创新大赛（2026）评审规则》官方 PDF（核查 2026-09-28）；教育部通知 教高函〔2026〕26 号
## 比赛介绍
国家级 A 类双创顶级赛事，三级赛制，提交创新创业项目，综合考察项目创新、商业落地与育人价值。
## 赛道设置
(1)高教主赛道：面向普通高校在校生，设本科生创意组/创业组、研究生创意组/创业组，覆盖新工科、新医科、新农科、新文科及人工智能+、低空经济等方向。
(2)青年红色筑梦之旅赛道：侧重社会价值与乡村振兴，聚焦农业农村、城乡社区等经济社会发展实际需求。
(3)职教赛道：面向职业院校学生，侧重技术技能与产教融合、区域产业需求。
(4)产业命题赛道：企业出题、学生揭榜，聚焦产业真实需求与解决方案落地。
## 评分标准（2026 官方评审规则）
高教主赛道·创意组（默认）：个人成长30% / 项目创新30% / 产业价值25% / 团队协作15%。
高教主赛道·创业组：个人成长25% / 项目创新30% / 产业价值30% / 团队协作15%。
红旅·公益组：个人成长30% / 公益价值10% / 项目创新20% / 发展前景20% / 团队协作20%；红旅·创意组：个人成长30% / 项目创新30% / 发展前景20% / 团队协作20%；红旅·创业组：个人成长25% / 项目创新30% / 发展前景25% / 团队协作20%。
职教·创意组：个人成长30% / 项目创新30% / 产业价值25% / 团队协作15%；职教·创业组：个人成长25% / 项目创新30% / 产业价值30% / 团队协作15%。
产业·企业命题组：个人成长30% / 项目创新20% / 团队协作20% / 实现成效20% / 项目分析10%；产业·成果转化组：个人成长25% / 项目创新30% / 产业价值30% / 团队协作15%。
## 申报书章节
(1)执行摘要
(2)项目背景与痛点分析
(3)产品 / 技术方案
(4)市场分析
(5)商业模式
(6)营销策略
(7)创业团队
(8)财务分析与融资计划
(9)风险分析与应对方案
(10)社会价值
(11)未来发展规划
(12)附录佐证材料
## 偏好方向
优先硬科技成果转化、专创融合项目；
偏好面向国家战略（乡村振兴、国产替代、绿色低碳、民生康养）、有原型 / 试点订单、学生主导、具备可落地商业模式的项目；
不喜欢纯概念、简单 API 套壳、同质化餐饮文创类项目。
## 常见扣分点
(1)材料造假、知识产权纠纷、跨赛道重复申报，直接取消资格
(2)执行摘要冗长，无量化成果，创新点空洞，只有数字化套话
(3)市场分析只写大盘，缺少细分目标市场与一手调研数据
(4)财务预测虚高，收入推导无依据
(5)股权集中于老师 / 外部人员，团队分工模糊
(6)商业模式不清晰，无法讲清盈利逻辑
(7)申报书与路演 PPT 数据前后矛盾，夸大项目效果
