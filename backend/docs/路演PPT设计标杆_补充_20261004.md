## 0. 适用场景与总原则（沿用 v1，本版强化）
- 路演 PPT = 「视觉化故事脚本」，更是「投资决策前的项目简报」。
- 评委日均看 50–80 个项目；7 秒抓眼球、3 分钟建信任。

## 1. 决策导向三原则（v5 新增，来源：rrmt.cn 创服复盘 + 李昕教授佐证）
- **原则一 · 信息密度降下来**：一页 ≤5 要点，否则评委只记住最大字号那个。删除一切不直接支撑核心结论的信息。
- **原则二 · 先结论后证据**：每一屏顺序 = 结论 → 理由 → 证据（不按时间线/项目发展线）。网评可「背景—需求—方案—优势—规划」，决赛每屏须回答评委一个潜在质疑。
- **原则三 · 一页一核心**：每页只有一个核心信息，其余全是支撑它的证据。自检：「这页对应评委哪个潜在质疑？」答不上就删。

## 2. 标准叙事 = 五大幕（v5 新增）
第一幕（约2页）定义一个「不得不解决」的问题（让评委3分钟内意识到严重性与普遍性）→ 第二幕 为什么是你（壁垒/专利/团队）→ 第三幕 怎么解决（方案+产品+演示）→ 第四幕 值不值得（市场/商业模式/财务）→ 第五幕 证据与信任（ traction/团队/愿景）。整体是一个「从具体问题走到可验证答案」的压缩创业故事。

## 3. 决赛时长预算（v5 新增，强约束）
- 正常语速 ≈220 字/分；决赛陈述环节 7–9 分钟，**全程可讲内容 ≤1800 字**。这点字数讲不了复杂故事，故叙事必须高度统一、可验证。
- iCAN 半决赛6分讲+4分答、总决赛10分讲+5分答；小挑/互联网+ 多为 5分讲+3分答（据高校校赛通报）。
- 导出物落点：路演稿须按赛事时长预算拆分「讲/答」字数；备用隐藏页承载技术参数与财务模型应对深度追问。

## 4. 黄金 12 页叙事链（沿用 v1）
封面(价值主张) → 痛点(场景代入) → 解决方案(技术可视化) → 产品(操作演示) → 商业模式(盈利逻辑图) → 市场(竞争格局画布) → 运营数据(traction 仪表盘) → 团队(成员标签化) → 财务(增长曲线) → 融资(资金用途) → 愿景(情绪高点) → 封底(记忆钩子)。

## 5. 视觉四原则（沿用 v1，本版补强）
- 痛点场景化 / 方案可视化 / 数据图表化（能用图不用字，强调色≤3）/ 团队人格化（标签化+实际投入，忌美颜图）。
- 李昕教授佐证「金字塔叙事+视觉锚点」「删减60%文字、增加产品场景图，路演评分提升一档」。
