## 一、互联网+（中国国际大学生创新大赛）2026 评审导向（来源：cy.ncss.cn 官方 + cxcyedu.com 复述官方）
- **造假一票否决**：科技成果/知识产权/财务/运营/荣誉须真实准确有效，弄虚作假、抄袭剽窃直接取消资格。
- **调研完整证据链**：问卷原始数据、访谈转写、带时间地点的实地照片、实验记录本均须归档；调研场所新增「企业」。
- **红旅赛道绑定「四个一线」**：科技创新 / 乡村振兴 / 城市社区治理 / 城乡融合发展；须指认具体一线场景与真实问题，且须参加由学校/省市/全国组织的「青年红色筑梦之旅」活动（参赛资格挂钩）。
- **专创融合成硬条款**：评审追问「项目是否从课堂里长出来」，计划书须专门说明与课程/专业/实验/科研训练/社会实践的逻辑联系。
- 导出物落点：红旅项目须在「背景与痛点」章显式标注四个一线场景与真实调研证据；通用项目须在「教育维度/引领教育」章写清专创融合链路。

## 二、iCAN 创新赛道 双盲评审官方口径（来源：g-ican.com 官方 + 高校转发附件）
- 双盲评审，专利/合同/论文**不作为**本赛道评审依据，重点聚焦产品实物本身与开发过程。
- 总分 = 巡展评分×20% + 分组答辩×80%。
- 巡展：实用性25 + 技术创新性25 + 现场演示效果50。
- 答辩：创新性35 + 实用性25 + 原创性20 + 技术方案20。
- **原创性20分**要求：构思到成品的开发过程可追溯、逻辑连贯，佐证材料真实有效，完整呈现研发过程与关键节点。
- 盲审违规（出现校名/单位名/导师名）每处扣5分。
- 赛程：半决赛6分讲+4分答，总决赛10分讲+5分答。
- 导出物落点：iCAN 项目须在「研发过程」章用时间线+节点佐证呈现「从构思到成品」可追溯链；全程盲审匿名。

## 三、国创/大创 结题「优秀等次」硬门槛（来源：5 所高校官方结题通知 2025-2026）
- 合格 = 国创/省创满足 2 项结题条件（必选1+可选1）；优秀 = 至少满足 3 项且层级更高。
- 优秀必含硬成果之一：学生一作核心/SCI 论文或发明专利授权；实用新型/软著(一作)；B 类及以上竞赛省一等奖/国奖；研究报告获县以上政府或市以上行业协会盖章采纳；实体公司持续经营且季度营收超 2 万（完税/对公流水凭证）。
- 研究报告须附知网查重 ≤15-20% + AIGC 检测，查重率低于 20%。
- 同一成果不得重复用于不同项目结题，成果须立项后取得且与项目直接相关。
- 导出物落点：国创结题报告须把「成果清单 + 佐证路径 + 查重达标说明」作为硬结构章。

## 四、挑战杯 科技发明制作类 评分权重 + 第4权重澄清（来源：5 所高校评分细则）
- 主干权重各校一致趋势：**创新性≈30 + 可行性≈30 + 科学性与先进性≈20 + 第4项≈20**。
- 第4项各校表述不一（以本校通知为准）：wids=评委评审意见20；ncpu=社会价值20+团队15+答辩10；nankai A类=现实意义40+综合10；hznu=现实意义45。
- 导出物落点：科技发明申报书须同时覆盖技术硬指标与「经济效益+推广价值+成熟度+答辩表现」软指标，避免只写技术。
