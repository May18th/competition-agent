## 蒸馏_v8（2026-10-09 · 联网可用，15 类高质量来源过门禁）

### v8.1 挑战杯(大挑) 三类作品评审标准精确占比
- 自然科学类学术论文 = 科学性40(科学意义15/研究方法合理性10/结论重要性15) + 先进性30(先进10/创新10/难度10) + 现实意义30(应用价值15/影响范围15)
- 科技发明制作 A/B 类 = 科学性30(技术意义15/技术方案最佳化15) + 先进性30(先进10/自主创新与难度20) + 现实意义40(效益与可持续30/成熟程度10)
- 哲社类社会调查报告 = 科学性30(理论基础研究方法10/论据严密可靠10/论据正确10) + 先进性30(创新10/难易10/学术水平10) + 现实意义40(经济效益社会效益20/影响范围20)
- 导出物落点：按作品类别套用对应占比；社科类重「论据严密可靠+影响范围」须附调研方法章与样本说明；科技类重「效益与可持续+成熟程度」须附发明点对比表与样机状态。
- 来源：tuanwei.lygsf.edu.cn（连云港师范团委）+ gqt.org.cn（团中央）。注：本届次初筛/终审核准比例随届次微调，以当届章程为准，不写死。

### v8.2 大挑 评审两阶段与书面评审地位
- 初评约 35% 进终审、55% 获三等奖、10% 淘汰（比例随届次微调）；终审三类各 5%/10%/20% 评特/一/二。
- 书面评审在初评占一定比重，评委会综合科学性/先进性/现实意义；材料严谨性与终审答辩同等重要。
- 导出物落点：兼顾书面材料严谨性（参考文献/数据三角验证/格式规范）与终审答辩表现，禁只有情怀无证据、禁格式硬伤。
- 来源：xtw.swupl.edu.cn（西政团委）+ tiaozhanbei.net（挑战杯官网）。

### v8.3 红旅「双轮驱动 / 造血机」组织逻辑
- 红旅本质 = 用商业手段解决社会问题；核心逻辑「公益价值 + 商业可持续有机融合，造血机而非输血站」。
- 三要素：需求接地气（扎实田野调查避伪需求）/ 方案有抓手（公益目标+商业路径双轮）/ 成果有依据（真实合作协议、服务数据、用户反馈）。
- 选题：小切口大价值（科技支教/非遗活化）；路演情怀+逻辑双线，数据支撑可视化，禁纯情怀。
- 来源：sei.sufe.edu.cn（上海财大创业学院，陈伟教授评委复盘）。

### v8.4 红旅 国金复盘：长期主义 + 答辩节奏
- 可复用路径：长期主义（历时数载系统实践）→ 集中辅导凝练立意/明晰架构/优化答辩节奏 → 多轮模拟演练层层过关 → 学术严谨+执着奋斗。
- 导出物落点：体现长期实践积累 + 社会价值量化 + 答辩节奏打磨，禁短期拼凑；须有真实服务数据与过程证据。
- 来源：rxgdyjy.sdu.edu.cn（山东大学儒学院 2025 国金复盘）。

### v8.5 互联网+ 网评版 / 路演版 结构差异 + 三处数据一致
- 材料三层：word版（网评补充，图文并茂）/ 网评PPT（35-40页精简）/ 路演PPT（16-20页核心精练，禁直接套网评PPT）。
- PPT版须与 word版数据一致、避错别字/逻辑错误、结构避千篇一律、增强跳跃感与对比度；网评靠材料、路演靠表现（答辩是关键得分点）。
- 导出物落点：显式区分网评PPT与路演PPT两类产物，并维持申报书/网评PPT/路演PPT 三处数字互锁（强化 V7.3）。
- 来源：gwcxcy.gdufs.edu.cn（广外）+ xsc.gzist.edu.cn（广州理工，华南师大侯永雄讲座）。

### v8.6 国创 结题验收精确指标体系 + 优秀门槛
- 验收 100 分 = 研究过程35(内容10/方法10/资料5/操作10) + 研究成果35(报告10/成果8/创新10/应用7) + 研究收获5 + 答辩25(陈述10/答题10/整体5)。
- 优秀须满足论文/专利软著/竞赛获奖之一；优秀比例约 22%-30%。
- 导出物落点：过程性时间轴 + 成果清单（标状态）+ 答辩PPT（陈述重点突出），与 V7.2 一致并补精确占比与优秀门槛硬约束。
- 来源：seit.sysu.edu.cn（中山大学验收指标体系 PDF）+ chuangye.qut.edu.cn（青岛理工 2025 结题通知）。
