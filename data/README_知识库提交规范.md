# 比赛知识库 —— 资料提交规范（给负责收集赛事资料的队友）

> 这份文档**不用你写代码**，只要照着填 txt 文件丢进 `data/` 目录就行。
> 下面每一条都对应程序里真实的读取逻辑，写错名字会导致「AI 读不到你辛苦整理的资料」。

---

## 一、文件放哪、什么格式

| 项目 | 要求 |
|---|---|
| 目录 | 项目根目录下的 **`data/`**（和 `app.py` 同级） |
| 格式 | **`.txt` 纯文本**，不要 Word、不要 PDF、不要 Excel |
| 编码 | **UTF-8**（Windows 记事本另存时选「UTF-8」，不要选「带 BOM」） |
| 大小 | 建议 **800～3000 字**。太短 AI 拿不到有效信息（低于 300 字基本无效） |
| 一个赛事一个文件 | 不要合并，不要分卷 |

## 二、文件名（最容易踩坑，务必照抄）

### 规则

后端匹配逻辑是（在 `competition_agents.py` 的 `get_competition_knowledge`）：

```python
if 文件名 in 用户选的赛事名 or 用户选的赛事名 in 文件名:
    命中
```

即：**你的文件名必须是网页下拉框里那个选项名的「连续子串」**（字字相连，不能跳字），反之亦然。

## 三、文件里必须包含这 5 个章节（少一个系统会标红）

程序会检查关键词，**缺任意一项该赛事的格式校验会显示「不完整」**。请照抄下面 5 个二级标题，**一个字都别改**（改了关键词就匹配不上）：

```markdown
## 比赛介绍
## 评分标准
## 申报书章节
## 偏好方向
## 常见扣分点
```

### 每章写什么

| 章节 | 内容要求 | 建议字数 |
|---|---|---|
| **比赛介绍** | 主办单位、参赛对象、赛程阶段（校赛/省赛/国赛）、组别划分 | 150-300 字 |
| **评分标准** | **最重要！** 各维度名称 + **百分比权重**，最好给表格 | 200-400 字 |
| **申报书章节** | 申报书**必须包含**哪几块内容（用于自动校验用户申报书是否漏写） | 150-300 字 |
| **偏好方向** | 该赛事偏爱什么类型的项目（如硬科技/社会价值/落地成果） | 100-200 字 |
| **常见扣分点** | 评委常见扣分理由、往年高频失分点 | 150-300 字 |

### ⭐ 评分标准怎么写最有价值

这是我们 AI 生成内容时唯一真正依赖的部分。请写成这样（有具体数字，AI 才能照着打分）：

```markdown
## 评分标准

| 维度 | 权重 | 说明 |
|---|---|---|
| 创新性 | 30% | 是否有原创技术或模式创新 |
| 商业性 | 25% | 盈利模式清晰度、市场空间测算 |
| 团队 | 20% | 学科交叉、分工合理性 |
| 就业与社会价值 | 15% | 带动就业、社会问题导向 |
| 引领教育 | 10% | 产教融合、成果转化 |

国赛网评阶段创新性权重上浮至 35%，现场赛商业性权重更高。
```

❌ 不要写「评分很公平、主要看综合实力」这种没有信息量的话。
