# 演示模式后端接口说明（供前端对接 · 270 轮）

> 目的：评委「一键演示」不走真实生成、不受 demo 只读 403 影响，直接渲染完整结果页。

## 接口

### 1. 取样例清单（下拉选择）

```
GET /api/demo/list
```

返回：
```json
{
  "success": true,
  "samples": [
    {"name": "一个「识别—提示—核验」闭环的校园智能分类桶…", "competition_name": "iCAN大学生创新创业大赛"},
    {"name": "一个「守护—陪伴—预警」闭环的智能助老终端…", "competition_name": "iCAN大学生创新创业大赛"}
  ]
}
```

### 2. 取单个样例结果

```
GET /api/demo?id=0   # 第 1 套（校园垃圾分类，默认）
GET /api/demo?id=1   # 第 2 套（智能助老机器人）
```

返回 `{"success": true, "data": {...完整结果...}}`。无预置样例时回退到最新一条深度版历史记录。

## data 字段（前端结果页要用的关键字段）

| 字段 | 说明 |
|---|---|
| `competition_name` / `idea` / `one_liner` | 赛事 / 创意 / 一句话定位 |
| `tier` | `"deep"`（按深度版渲染） |
| `score` / `idea_score` | 文档质量分 / 创意分 |
| `dims` | 评分维度（iCAN 创新赛道 = 创新性35/实用性25/原创性20/技术方案20） |
| `scores` | 各维度得分（雷达图用） |
| `proposal` | 申报书正文（Markdown） |
| `competitor_analysis` / `business_model` / `risk_analysis` / `tech_solution` / `implementation_plan` / `social_value` | 各分析板块 |
| `defense_questions` / `ppt_outline` / `judge_feedback` / `proposal_analysis` | 答辩 / PPT 大纲 / 评审意见 / 诊断 |
| `rich_deck` | PPT 结构（`slides` 数组，每项 `type/title/bullets/note`），直接喂现有 PPT 预览 |
| `rich_charts` / `rich_tables` | 空数组——前端用现有 `__wbDemoChartDraw` ECharts 兜底渲染即可 |

## 前端接法

1. 「一键演示」按钮 → `GET /api/demo/list` 出下拉（2 套样例）。
2. 用户选一套 → `GET /api/demo?id=N` 拿到 `data`。
3. 把 `data` 当作一次「生成结果」喂给现有结果页渲染逻辑（`renderResult(data)` 之类），
   评分 / 正文 / 各 tab / PPT 预览 / 图表兜底 全部复用，无需走 `/api/generate_async`。

## 注意

- `/api/demo` 是公开 GET，无鉴权、不调 LLM、不写库，demo 只读会话和匿名都能访问。
- 前端导出演示结果时，仍走现有导出接口（demo 会话有 `comp_uid` cookie，可导出）。
