**其它**：历史记录、分享链接、额度徽章（右上角 #quotaBadge）、运行日志 Tab（隐藏）、管理后台入口（/admin）。

### 前端核心机制
- **异步生成**：POST `/api/generate_async` 拿 task_id → 定时 GET `/api/status/<task_id>` 轮询 → 读 `stage_label`/`pct` 画进度条（只涨不跌），`partial` 增量渲染逐字流式内容。
- **渲染统一入口**：`wbRenderMD()`（marked + purify + 去重 + 底部智能辅助声明）。
- **导出**：`exportOne()` 系列函数，读 X-PDF-* 响应头展示页数/体积/上限，`export_quality_fail` 时展示后端 suggestions。

### Agent 流水线（competition_agents.py，21 个 Agent）
**简洁版 fast_app**（~77s）：rule_parser → similarity → (writer → judge → proposal_analysis) → defense/ppt 并行。
**深度版 deep_app**（~160s）：rule_parser → similarity → 6 个分析 Agent 并行扇出（deep_competitor/business/risk/tech + plan + social_value）→ summary → 深度三段链（_build_outline 构思纲要 → deep_writer 正文（逐字流式）→ _selfcheck 自检）→ judge → expert_review → proposal_analysis → should_iterate? → targeted_revise → defense/ppt/speech 并行 → one_liner → rich_media。

**Prompt 规格（本地 419 轮新增）**：`_QUALITY_BENCHMARK_SPEC` 已注入 `_REPORT_SPEC/_PROPOSAL_SPEC/_ANALYSIS_SPEC/_BRIEF_SPEC/_FULL_SPEC` 5 个 spec，内容含：iCAN 字数上限（简介≤400/创新≤200/实用性≤200/技术方案≤300）、挑战杯三类评分权重、佐证材料硬要求、痛点写法、团队章规范、图表规范、防污染四禁令（禁编造/禁裸数字/禁断言已发生/禁第三方原文）。

### 质检闸门（导出前必过）
| 闸门 | 模块 | 规则 |
|---|---|---|
| check_docx / check_word_toc | quality_gate / export_guard | 600字以上必须有封面+目录；Heading1~3 任一存在即可；短文档(<2500字)豁免 TOC |
| check_pdf | quality_gate | 按赛事查表（iCAN ≤20页/10MB，挑战杯 ≤30页/15MB，默认 40页/20MB）；超限返回带数字的 suggestions |
| check_pptx + 大纲页数闸门 | quality_gate + app.py | PPT 页数与大纲差 ≥2 页拦下（code=ppt_outline_mismatch，422），提示取消「路演重排（固定8页）」 |
| check_zip | quality_gate | 体积/文件数 |

## 四、前后端接口对照（关键链路）

| 前端动作 | 接口 | 后端处理 |
