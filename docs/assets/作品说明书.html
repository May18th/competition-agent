科创赛事多智能体协同创作助手

作 品 说 明 书

一、项目背景

「科创赛事多智能体协同创作助手」是面向大学生科创竞赛团队的端到端多智能体系统，基于 Flask + LangGraph 多智能体编排开发，实现赛事规则解析、创意同质化检测、申报书智能生成与优化、模拟评委评审的全流程自动化，目标是显著降低学生参赛的内容生产与格式打磨门槛。

近年来大学生科创赛事规模持续扩大。据教育部、人民日报等公开口径，中国国际大学生创新大赛（2025）覆盖 161 个国家和地区、5673 所学校、619 万个项目、2443 万人次参赛，总决赛入围 4720 个项目。在如此体量下，参赛团队普遍面临"不知道评委要什么、材料反复改格式、不同比赛规则各异难以复用"的真实困境。

本作品以 iCAN 大学生创新创业大赛、中国国际"互联网+"大学生创新创业大赛、挑战杯、国家级大创等赛事为首批内置知识库对象，把"读懂评分标准 → 检测撞题风险 → 生成/优化申报书 → 模拟评委打分"这一评审逻辑固化成可复用的智能体流水线，让单个学生也能产出接近团队水平的参赛材料。

二、痛点分析

1. 学生侧真实痛点（脱敏后的通用场景）

  • 写申报书写了一周，仍然不清楚评委到底在考察什么。
  • 做展示 PPT 要反复调格式、想表达，耗时远大于内容本身。
  • 不同比赛的模板、评分标准各不相同，一份材料无法复用，改了又改。

2. 现有竞品的不足（公开评价）

  • 秘塔写作猫：免费版仅能体验，正常需开会员（24 元/月、48 元/月两档）；在 Safari 上兼容性差；定位偏"校对/润色/摘要"，并非完整申报书全流程工具。
  • 讯飞写作：手机 App 功能偏极简，缺少比赛差异化模板；公开评测指出其大模型存在直接输出未经核实数据（幻觉）的风险。

3. 竞品缺口

现有工具多是"通用写作助手"，缺少"按具体比赛评分标准生成 + 多智能体协作 + 图表/PPT 联动"的完整链路——这正是本作品切入的位置。

三、需求分析

由上述痛点可推导出核心需求：

  • 标准对齐：系统必须内置各赛事的评分维度与权重，让生成内容直接对标评审标准，而非泛泛而谈。
  • 全流程覆盖：从规则解析、同质化检测、文稿生成到模拟评委评审，形成一条可端到端跑通的生产线。
  • 差异化输出：支持按"简洁版 / 深度版"提供不同深度的结果，并支持 Markdown / Word 多格式导出，适配不同赛事材料要求。
  • 可复用与可演进：本地赛事知识库 + 历史记录存储，使同一项目可多次迭代、跨赛事复用。

四、目标用户群体

  • 参赛学生个人：单人参赛、缺乏团队支撑，需要快速产出合格申报书与答辩材料。
  • 高校科创竞赛团队：iCAN、互联网+、挑战杯、国创等赛队的负责人与成员，需要标准化、可复用的内容生产工具。
  • 指导教师（辅助侧）：用于快速把脉学生项目的撞题风险与材料短板，提高指导效率。

五、功能需求

核心模块分为 4 部分（赛事知识库、核心引擎、版本区分、导出中心），并围绕"简洁版 / 深度版"提供差异化的功能深度：

功能简洁版深度版

六、开发工具

  • 后端框架：Flask（REST API，处理文件上传、生成请求、导出接口）。
  • 多智能体编排：LangGraph（多 Agent 工作流编排，可并行环节并行，如深度版写作拆两段并行）。
  • 大模型服务：DeepSeek 大模型 + 火山引擎 Claude。
  • 前端：HTML / CSS / JavaScript（用户交互与结果展示）。
  • 数据存储：本地比赛知识库 + SQLite 历史记录。

七、技术方案

系统从前端到存储分为 5 层：

  • 前端页面层：HTML/CSS/JS，负责用户交互和结果展示。
  • Flask 后端 API 层：处理文件上传、生成请求、导出接口。
  • 多智能体编排层：多 Agent 工作流编排（可并行环节并行，如深度版写作拆两段并行）。
  • 模型服务层：DeepSeek 大模型 + 火山引擎 Claude。
  • 数据存储层：本地比赛知识库 + SQLite 历史记录。

完整运行流程：用户输入 → 选择比赛 → 输入项目创意 / 上传申报书 → 选择版本 → 规则解析 Agent 提取评审标准 → 同质化检测 Agent 评估撞题风险 → 文稿生成 Agent 生成 / 优化申报书 → 评委评审 Agent 打分并给出改进建议 → 结果展示 → 导出文件。

八、作品功能逐一说明

  • 赛事知识库：内置 iCAN、互联网+、挑战杯、国创等比赛规则与评分口径，作为生成与评审的"标准底座"。
  • 规则解析 Agent：从所选赛事规则中提取评审维度、权重与扣分点，为后续生成提供对齐目标。
  • 同质化检测 Agent：评估项目创意与已有获奖/在研方向的撞题风险，提示差异化空间。
  • 文稿生成 Agent：依据评分标准生成或优化申报书（简洁版 2000~4000 字级，深度版约 12000 字级），深度版额外产出竞品/商业/风险分析、技术方案与实施计划、答辩问题与 PPT 大纲。
  • 评委评审 Agent：以模拟评委视角对成稿打分并给出改进建议，形成"生成—评审—优化"闭环。
  • 导出中心：支持一键导出全部结果，或单独导出各模块，提供 Markdown / Word 格式，适配不同赛事材料要求。

九、AI 功能核心作用

本作品的 AI 能力并非"通用续写"，而是围绕评审逻辑设计的多智能体协作：

  • 按标准生成：以规则解析 Agent 产出的评审维度为锚，让生成内容直接对标评分权重，减少"偏题"。
  • 风险前置：同质化检测在学生动手写之前就提示撞题风险，避免方向性返工。
  • 闭环评审：评委评审 Agent 把"专家打分"前置到创作阶段，使成稿在提交前完成一轮自我修正。
  • 并行提效：编排层对无依赖环节并行执行（如深度版写作拆两段并行），把"团队数天"压缩到"分钟级"。

十、使用说明

  • 打开前台网站（https://kechuang2026.cn），进入创作首页。
  • 选择目标赛事（如 iCAN、互联网+ 等），输入项目创意或上传已有申报书草稿。
  • 选择版本：简洁版约 1–2 分钟快速出结果，适合先摸底；深度版约 3–5 分钟，产出完整申报书及竞品/商业/风险分析、技术方案、答辩问题与 PPT 大纲。
  • 查看规则解析、同质化检测、文稿与评委点评结果。
  • 在导出中心一键导出全部结果，或单独导出各模块（Markdown / Word）。

评审 / 体验账号：前台与后台共用同一登录入口 https://kechuang2026.cn/admin/login，提供演示账号 demo / 123456 供评审与体验使用；后台管理端另设管理账号，credentials 由团队持有，不随本说明书公开。

十一、应用前景

  • 市场空间：据 QYResearch 估算，全球 AI 写作辅助软件市场 2025 年约 53.57 亿美元，2032 年预计 201.1 亿美元，年复合增长率约 20.8%（第三方调研，口径为估算，非既定事实）。大学生科创赛事参赛规模持续处于千万级人次，存在明确且稳定的工具需求。
  • 赛事可扩展性：当前已内置 iCAN、互联网+、挑战杯、国创等规则，知识库可按新赛事持续扩充，能力向更多学科竞赛、课程大作业、科研立项书等场景延展。
  • 教学辅助价值：可作为高校双创教育的实训工具，把"评审标准意识"前置到学生创作全过程。

十二、商业模式

  • 版本分级（Freemium）：简洁版满足快速摸底与轻度使用，深度版面向需要完整申报书与商业/风险分析、答辩材料的重度用户，对应差异化付费。
  • 对标参考：同类写作辅助工具普遍采用会员制（如竞品 24 元/月、48 元/月两档），本作品可参照设置个人订阅档位。
  • 机构授权：面向高校双创学院、实验室提供院校级授权与私有化部署，按席位或年度授权收费。
  • 增值服务：围绕申报书生成延展的 PPT 大纲、答辩问题、查新/同质化检测等可作为增值模块，形成"生成—评审—提交"闭环内的持续付费点。
