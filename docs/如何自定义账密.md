# 如何自定义后台账号密码（198 轮账号体系）

后台已从「单一口令」升级为「用户名 + 密码」账号体系，密码用 **bcrypt 哈希**存储，禁止明文。

## 一、账号配置位置

账号列表从环境变量 `ADMIN_USERS`（JSON）读取；未设环境变量时，读项目根目录 `.admin_users.json` 文件。

格式（JSON 数组，每项三个字段）：

```json
[
  {"user": "admin", "pass_hash": "<bcrypt哈希>", "role": "admin"},
  {"user": "demo", "pass_hash": "<bcrypt哈希>", "role": "readonly"}
]
```

- `user`：登录用户名
- `pass_hash`：密码的 bcrypt 哈希（不是明文）
- `role`：`admin`（完整权限）或 `readonly`（只读，写操作一律 403）

## 二、在服务器上设置（推荐用 .env）

编辑 `/opt/comp-agent/.env`，加一行（JSON 需要转义成单行）：

```bash
ADMIN_USERS=[{"user":"admin","pass_hash":"<bcrypt哈希>","role":"admin"},{"user":"demo","pass_hash":"<bcrypt哈希>","role":"readonly"}]
```

改完重启生效：

```bash
systemctl daemon-reload
bash /opt/comp-agent/scripts/safe_restart.sh
```

## 三、怎么生成 bcrypt 哈希

在服务器（或任意装了 bcrypt 的 Python 环境）执行：

```bash
python3 -c "import bcrypt; print(bcrypt.hashpw('你的密码'.encode(), bcrypt.gensalt()).decode())"
```

把输出的 `$2b$12$...` 填到 `pass_hash` 字段即可。

## 四、回退说明（兼容旧部署）

- 若 `ADMIN_USERS` 未配置，会回退到旧的单一口令模式：`ADMIN_TOKEN`（管理员口令）和 `DEMO_TOKEN`（演示只读口令）。
- 一旦配置了 `ADMIN_USERS`，旧的单一口令模式不再生效，以账号体系为准。

## 五、安全提示

- 密码哈希文件/环境变量别提交 git；明文只存服务器 secrets（用完删）。
- 登录连续 5 次失败锁定 15 分钟；登录成功/失败都会写审计日志（用户名 + IP + 角色）。
