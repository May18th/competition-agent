## 1. 章节结构共性（优秀申报书/计划书的骨架）

### 1.1 大挑·自然科学类学术论文（8 段式）
题目 → 摘要 → 关键词 → 引言 → 研究方法与结果 → 讨论 → 结论 → 参考文献。
- 题目 ≤20 汉字，避免缩略语/公式，反映研究范围与深度。
- 摘要 300–500 字、第三人称、开门见山，必须覆盖四要素：研究目的与重要性 / 主要内容 / 结论成果（突出新见解）/ 意义。
- 引言按固定逻辑链展开：研究目的意义 → 前人最主要进展（高度概括）→ 切入点（前人薄弱环节或空白，点题）→ 拟解决的关键问题 → 预期结果与地位意义。
- 讨论避免重复引言/结果数据，推论不超出数据支撑，表述"适当留有余地"。
- 参考文献 ≥20 篇且含外文文献，体现领域前沿。
- 来源：公众号「大学生科研竞赛」《大挑申报书，这么写就对了——（一）自然科学类学术论文》

### 1.2 大挑·哲社类调查报告（3 段式 + 4 方法）
前言 → 正文 → 结尾。
- 前言交代：调查动机 + 时间/地点/对象/范围/经过/方法。
- 正文写：事实真相、收获经验教训（人物、事件、问题、做法、障碍），有层次推进。
- 结尾四型任选：归纳总结深化主题 / 展望方向 / 坦陈尚存不足 / 补充正文未涉的重要情况。
- 研究方法显式交代（文献综述/问卷/访谈/实地观察），问卷需说明渠道与回收口径。
- 来源：公众号「大学生科研竞赛」《大挑申报书，这么写就对了——（二）哲学类调查报告和学术论文》

### 1.3 大挑·科技发明制作说明书（5 要素）
研究报告无固定格式，但必有五块：**研究背景、技术原理、实验数据、研究创新、竞争分析**；附曲线、试验数据、原理结构图、实物外观图。官方申报书 B 表必填：设计目的与基本思路 / 创新点与技术关键和主要技术指标 / 科学性先进性（必须与现有技术对比说明"突出的实质性技术特点和显著进步"，附技术性分析与参考文献）/ 使用说明与适用范围 / 推广前景与市场分析及经济效益预测。
- 来源：公众号「米有校园」《挑战杯（大挑）详细备赛攻略 | 科技发明制作类》；公众号「大学生科研竞赛」《大挑申报书，这么写就对了——（三）科技发明制作说明书》

### 1.4 互联网+/小挑·商业计划书（9 章标准结构）
项目名称 → 背景分析 → 产品介绍 → 市场分析 → 团队介绍 → 商业模式 → 社会效益 → 财务预测 → 风险预测。各章职责：
- 名称：让评委第一步就了解目标与优势，与后文解决的问题吻合。
- 背景分析：社会/市场现象 → 调研证实痛点广泛存在 → 国家政策呼应 → 解决决心（价值观与家国情怀在此自然带出）。
- 产品：功能+技术之外，必须指出哪些是别人没有的、达到什么水平、专利/软著等壁垒，以及团队与产品的真实关系。
- 市场分析：容量+潜力+竞争分析，服务商业落地论证。
- 团队：组成原则与过程科学合理，体现知识/技术/经验与项目的匹配。
- 商业模式：客户群体、营销方式、盈利模式、战略方向。
- 社会效益：商业收益之外的附加价值（就业、教育等）。
- 财务预测：投入、成本、销量、融资计划。
- 风险预测：提前预测并给出管理措施。
- 来源：公众号「新大陆时代科技」《新分享 | "互联网+"大赛商业计划书撰写指南》

### 1.5 网评 PPT/材料的信息排布
- 项目现状应高度概括，网评版 PPT 放第一页。
- 顺序要点：现状 → 政策与市场 → 行业痛点（从市场分析中提炼，必须精确）→ 解决方案。
- 大忌：封面-目录-背景-技术方案"按部就班"，不考虑评委注意力曲线；**前 3 页必须出现痛点+方案+硬数据**。
- 来源：公众号「广外创新创业学院」《创客讲坛第27讲：第八届"互联网+"大赛分析及商业计划书撰写干货分享》（主讲含广东省就业促进会常务副会长、天使投资人）；公众号「保研竞赛嘉油站」《挑战杯省赛评委群聊实录》

### 1.6 通用结构纪律
- 申报书目录**不要千篇一律格式化**，要凸显项目自身特色、让评委一目了然（国一团队经验）。
- word 版计划书内容详尽、图文并茂；PPT 版与之数据完全一致；避免错别字与逻辑错误。
- 来源：中国社科大团委《挑战杯国赛一等奖经验分享！》 https://youth.ucass.edu.cn/info/1008/2659.htm ；创客讲坛（同上）

## 2. 数据呈现规范

1. **市场数据双轨验证**：自上而下（国家统计局/权威行业白皮书锁定规模）+ 自下而上（实地走访 N 城市 / M 家企业深度访谈 + 问卷 N 份），并报出有效样本数、置信度、误差范围。二手报告与实地调研结论不一致时，说明差异并给出自己的判断依据。
2. **三级数据口径显式区分**：实测值（标来源与测试条件）、测算值（标推导逻辑）、预期值（标假设前提）。混用即扣分项；仿真/推算写成实测属于造假级错误。
3. **单一指标必须带基线与场景**：不说"准确率 97%"，要说"准确率 97%，比现有方案提升 35%"；准确率需区分场景类型与样本构成，否则无法横向比较。
4. **投资人语言指标**：LTV/CAC 倍数、单位经济模型（UE）、月度盈亏平衡时点、累计现金流转正时点、复购率/续费率、预收款。
5. **财务模型三情景**（保守/中性/乐观），成本结构按比例拆解（原材料/人工/营销各占多少、如何锁定波动风险），所有假设回溯到实际试点数据（如获客成本按前 100 个付费客户实际支出测算）。
6. **证据链可查**：调研原始数据、录音、问卷截图、合同、流水整理成册，评委问到能当场翻出。
7. **图表配置**：技术类必有曲线/原理结构图/实物图；答辩与报告用图表替代文字堆砌；PPT 与 word 数据一致；图片本身也是真实性证据（调研照片、实验设备、产品制作过程）。
- 来源：公众号「创赛导师」《2026挑战杯答辩急救指南：国赛评委爱问的10个"送命题"》；「保研竞赛嘉油站」《评委群聊实录》；「大学生科研竞赛」《（三）科技发明制作说明书》；本项目 judge_paradigm 已有口径（本次调研证实为评委共识）

## 3. 创新点论证模式

1. **「三新」框架**（获奖社科作品通用）：视角新（切入角度）/ 方法新（用了什么分析或技术方法）/ 对策新（输出什么可推广的路径）。每条一小段，各自独立成立。
   - 来源：公众号「长安大学马克思主义学院」《经验说 | "挑战杯"国赛一等奖经验分享》（第十八届大挑国一项目复盘）
2. **壁垒三层论证**（技术类通用）：数据壁垒（独家数据集/采集时间/授权难度）+ 算法/方案壁垒（针对场景的定制结构与可量化优势）+ 工艺/集成壁垒（与产线/场景深度耦合的调试积累）。每层都要有具体细节、数字、时间投入，让评委判断"真做过"。
   - 来源：公众号「竞赛有门道」《挑战杯（小挑）答辩现场，评委最爱问的"致命三连问"》（作者以评委视角拆解）
3. **弱技术项目的替代论证**：技术壁垒不高时，不硬撑，改论证"场景理解深度"——投入的调研时长、发现的核心痛点数、针对性优化项；"壁垒不是技术高度，而是场景理解的深度"。
4. **可验证表述**：创新点必须落到可核验载体——专利公开号、软著、科技查新报告、权威检测/鉴定报告、试用报告、投产证明、专家推荐书、往届获奖证书、媒体报道（简讯即可）。其中论文/专利/软著/查新报告是学生团队最易获取的四件套。
5. **官方对比句式**：与现有技术相比，是否具有"突出的实质性技术特点和显著进步"，需要技术性分析说明与参考文献支撑（这是评审标准的原文维度，申报书应直接对着这句话组织论证）。
6. **禁忌写法**：无对比数据的"国内领先/国际先进"；"这个技术只有我们会"；"大厂看不上这个小市场"（评委要正面论证，不要自我安慰式定位）。
- 来源：综合「创赛导师」「竞赛有门道」「米有校园」及官方评审规则解读

## 4. 痛点叙事手法（开头怎么抓住评委）

1. **痛点具体化公式**：人群 + 场景 + 行为/障碍 + 数字。反例："农村发展面临很多问题"（评委原话级批评：什么问题？有调研数据吗？）；正例模式："中国有 1700 万视障人士，80% 无法独立出行"——一个总规模数字 + 一个失败率/未被满足率数字。
2. **数据锚点开篇**：第一屏就给两个数字（规模 × 严重度），再进入叙事。
3. **前 3 页/前 3 分钟法则**：评委每天看几十个项目，前 3 页没有亮点后面再精彩也没用。开头必须完成"痛点 + 方案 + 数据支撑"三件事。
4. **递进结构**：社会现象（观察到什么）→ 调研证实（数据说明问题广泛存在）→ 政策呼应（国家出台了什么政策）→ 我们的切入点（为什么是现在、为什么是我们）。这同时完成价值观/家国情怀的自然植入，避免口号式表态。
5. **工作量数据入题**：题目可做艺术化表达，也可直接把工作量数据放进标题作为亮点（如调研覆盖 56 村这类）；题目宁小勿大——"某县某群体某问题"优于"中国XX问题研究"。
6. **真实感细节**：痛点描述带调研过程的具象细节（走访了多少地方、访谈中最大的困难是什么），这既是叙事也是可信度。
- 来源：「保研竞赛嘉油站」《评委群聊实录》；「新大陆时代科技」《商业计划书撰写指南》；中国社科大、长安大学国一经验分享；公众号「焦聚桂教」《大挑赛答辩技巧：常见路演答辩问题+回答方向》

## 5. 社会价值量化表达

1. **三维度量化模板**：经济（覆盖 N 户、户均增收 X 元/周期，数据来自当地政府部门统计）+ 环境（减少使用量/排放量，经第三方机构认证）+ 就业（带动 N 人就业、人均月收入 X 元）。
2. **区分已验证与预期**："已服务 50 位用户、独立出行成功率提升至 92%、家属满意度 96%"与"预计覆盖 10 万人"必须分开表述，前者是证据、后者是目标。
3. **成果背书清单**（申报书末尾的硬通货）：成果被 N 家单位采纳应用、学生发表核心论文 N 篇、获 N 位权威专家推荐、N 所科研机构评价、国家级/主流媒体报道 N 次、获政府资政认可/入选参阅文件。（长安大学国一项目即以此清单收尾）
4. **反面模式**："助力乡村振兴""服务碳达峰碳中和""推动教育公平"被称为"正确的废话"——正确但不可核验。改写公式：帮助了多少（具体对象）+ 增收/改善多少（具体数字）+ 谁出具的证明。
5. **大挑哲社类的对应表达**：对策部分写"分类研判、因地制宜"的可推广路径（如按对象类型给出 N 类模式），并注明成果被采纳的情况——社会价值落在"研究成果被实际应用"。
- 来源：「创赛导师」《评委10问》之社会价值拷问；「长安大学马克思主义学院」国一复盘；「保研竞赛嘉油站」《评委群聊实录》

## 6. 风险与可行性写法（坦诚但不失分）

1. **风险分级四段式**：识别 2–3 个真实风险（技术迭代/市场接受度/现金流）→ 每个按"现状 → 可能后果 → 缓解方案 → 兜底预案"展开。兜底要具体到可执行（已完成 70% 跨平台适配、已签 B 端意向采购可随时转向、专利评估估值 X 万元可资产处置）。
2. **"没风险"是最大的失分答案**；"资金不足"是无效答案（所有项目通病，不是你的特有风险）。
3. **巨头竞争的非对称论证**（商业类高频拷问）：分析巨头的能力边界与业务重心 → 说明本市场对巨头是"鸡肋"（单台利润高但总量小）→ 已构建的时间窗口（排他协议/渠道关系/成本结构差异）→ 极端情况的 B 计划（成为巨头的技术供应商）。忌"我们会更努力""巨头看不上"。
4. **可行性 = 落地证据而非承诺**：阶段定位（"产品验证期向市场复制期过渡"）+ 原型机代际 + 已签合同数与金额 + 试点场景数 + 团队投入量化（每周投入小时数）。用"已经"替代"预计/大概/正在对接"。
5. **资金使用规划**：给一笔钱怎么花——按比例分配（如 40% 研发/30% 市场/30% 团队）、每笔拆到具体动作与数量、12 个月内达到的可验证里程碑。
6. **适度坦诚加分**：被问倒时的标准姿态是"承认未深入研究 + 给出当前思路 + 承诺答辩后补充调研"；对小瑕疵（样本量、排版）大方接受并致谢，反而传递"团队具备快速迭代能力"的信号。
- 来源：「创赛导师」《评委10问》；「竞赛有门道」《致命三连问》；公众号「创赛创未来」《挑战杯答辩，评委越质疑，项目越加分》

## 7. 评委关注点排序（评审细则 + 评委视角交叉验证）

### 7.1 官方评审权重（大挑，以省赛规则为参考）
- 科技发明制作类：科学性 30%（科学意义 15 + 技术方案合理性 15）、先进性 30%（先进/创新/复杂程度各 10）、现实意义 30%（经济价值/推广价值/成熟程度各 10）、规范性 10%。**现实意义是与自然科学类拉开差距的重点。**
- 自然科学类：选题意义 20 / 研究方法与科学性 25 / 创新性与先进性 25 / 应用前景与成果转化 20 / 撰写规范 10。
- 哲社类：选题现实意义 20 / 调研方法与数据可靠性 25 / 分析深度与创新观点 25 / 对策建议可操作性 20 / 写作规范与逻辑 10。
- 来源：公众号「米有校园」「竞赛规划君/晓彤老师」对历届省赛评审规则的拆解

### 7.2 评委实际阅读顺序与判定逻辑
1. **前 3 页定生死**（注意力有限，痛点不清直接失分）。
2. **商业逻辑闭环六要素**：明确痛点 → 清晰方案 → 扎实验证数据 → 可行商业模式 → 合理财务 → 完整团队，**缺一不可**。"技术很强但商业论证缺失"得不了高分；"技术一般但闭环完整"反而可能高分——这是创新创业竞赛不是技术竞赛。
3. **数据 > 形容词**；**真实验证 > 概念说明**；**"已经" > "预计"**。
4. **评委提问的三重验证**：技术细节问的是"真懂还是知道"；落地细节（哪个工厂/多久/效果）问的是"真做过还是编的"；竞争与风险问的是"真想过还是只想了好的一面"。
5. **一票否决/严重扣分项**：实地调研情况回答不实（评委视角"一票否"）；盲审材料泄露院校/导师/成员信息；把仿真/测算说成实测；AI 套壳无核心贡献。
6. **加分细节**：政策支持引用具体政策文件；市场数据来自权威机构并可溯源；辅助证明材料四件套（论文/专利/软著/查新报告）；政府企业出具的采纳证明；现场可演示的实物或视频；答辩有交流感（眼神、停顿、第一人称、不抢话）。
7. **赛段差异**：网评靠材料（结构合理、内容丰富），路演靠表现（答辩大于 PPT）；省赛网评重视 word 版计划书，国赛阶段需强化财务报表。
- 来源：「保研竞赛嘉油站」《评委群聊实录》；「竞赛有门道」《致命三连问》；「广外创新创业学院」《创客讲坛第27讲》；「焦聚桂教」《大挑答辩技巧》

### 7.3 答辩回应通用公式
先接住（感谢/承认视角）→ 抛数据/事实证据 → 说明当前解法 → 承认评委建议是下一步优化方向。核心纪律：不对评委"科普"、不抢话、不纠结对错，目标是把否定度从 50% 降到 10%。
- 来源：「创赛创未来」《评委越质疑，项目越加分》

## 8. 常见失分写法清单（反面模式 → 与本项目生成内容的差距对照）

| # | 反面模式 | 评委反应 | 对 AI 生成内容的启示 |
|---|---------|---------|---------------------|
| 1 | 空话排比 / "正确的废话"（助力XX、赋能XX、推动XX 无数字） | 直接标记为社会价值虚浮 | 生成器最易犯：每章结尾升华段。需模式词检测 |
| 2 | 无数据论断（"技术先进、国内领先"） | "这句话没有任何意义" | 形容词必须绑定数字+基线，否则删 |
| 3 | 概念堆砌蹭热点（AI+/数字孪生+/元宇宙+ 拼接） | "为了蹭热点而加概念"，一眼识别 | 生成标题/方案时限制概念数量，每个概念须对应实际功能 |
| 4 | 术语堆砌不解决问题（技术写 12 页看不懂做什么） | "第 10 页还没明白要解决什么问题" | 技术章开头必须有一段非术语的价值陈述 |
| 5 | 痛点泛泛（"面临很多问题""需求旺盛"） | 视为无效数据、无调研 | 痛点章强制 人群+场景+数字 三要素 |
| 6 | 财务过乐观（年增 900%、毛利 85%） | "评委一眼看出不合理" | 生成财务数字需限制在合理区间并标注情景 |
| 7 | 市场规模拍脑袋（千亿市场占 1%） | 商业论证完全缺失 | 占有率推算必须给出获客路径支撑 |
| 8 | 模板腔结构（封面目录背景技术按部就班） | 不考虑注意力曲线 | 前 3 章/前 3 页信息密度重新分配 |
| 9 | 只讲技术不讲闭环（六要素缺项） | 技术强也低分 | 生成时做六要素完整性检查 |
| 10 | "预计/大概/正在对接"式落地描述 | 等于没说 | 落地章只写"已经"级事实，预期单独成段 |
| 11 | 答辩背稿、无交流感 | 像背课文，扣分 | 答辩稿生成要口语化+停顿标记+第一人称 |
| 12 | 格式硬伤（错别字、图表编号重复、两个版本数据不一致） | 规范性直接丢分（占 10% 权重） | 导出前做一致性校验（已有 export_guard 可扩展） |

与本项目现状对照：现有 writing_paradigm/judge_paradigm 已覆盖口径混用、AI 套壳、盲审泄露等 12 条评委批评；**本次调研新增的差距**主要是：①章节信息排布顺序（前 3 页法则、现状前置）无规范；②财务三情景/盈亏平衡/资金分配结构无模板；③社会价值三维度量化与成果背书清单无模板；④"三新/壁垒三层"创新点论证框架未落库；⑤风险四段式与巨头非对称论证未落库；⑥反面模式词表（正确的废话类）未进入质量门。

## 9. 可落地改进建议（写入生成 prompt / 范文库的优先级）

### P0（直接决定评委第一印象，立即写入章节模板）
1. **开篇重组**：申报书/计划书第一章改为"项目概览"——一段话交代服务对象、核心问题、技术手段、最硬的量化成果（现有 modules.项目简介已有雏形，需强制"量化指标前置 + 两个锚点数字开篇"）；网评 PPT 第一页放项目现状高度概括。
2. **痛点章三要素强制**：人群+场景+带来源数字，至少 3 个数据锚点（总规模、严重度、增速/未被满足率），并显式交代调研过程（走访 N 处/访谈 M 人/问卷 K 份有效回收率）。
3. **数据三级口径全文档强制标注**（实测/测算/预期），正文用统一标记（如"（实测）""（测算，基于XX假设）"），杜绝混用——此项已有口径共识，需从"批评用语"升级为"生成规则"。
4. **财务章模板化**：三情景表 + 成本结构百分比拆解 + 盈亏平衡月/现金流转正月 + 资金分配比例与里程碑。数字区间约束：增长率、毛利率需带"保守情景"兜底，防 900% 式翻车。
5. **社会价值章三维度模板**：经济/环境/就业各一条"已验证数字 + 出证方"，预期目标单独成段；文末附"成果背书清单"章节（论文/专利/软著/采纳单位/报道，缺项则列"可获取路径"）。

### P1（显著提升论证质量）
6. **创新点双框架**：技术类用"壁垒三层"（数据/方案/集成，每层须有细节+数字+时间），社科类用"三新"（视角/方法/对策）；并强制与"现有技术对比"句式挂钩。
7. **风险章四段式**：现状→后果→缓解→兜底，2–3 个真实风险，禁写"无重大风险"和"资金不足"。
8. **竞争分析表格化**：4–6 个可量化维度对比表，结论写"在 X 维度领先/持平"，对接 analysis_paradigm.competitor 的现有规范并补充"巨头非对称论证"段。
9. **章节篇幅配比指导**：痛点+方案+验证数据合计应占前 40% 篇幅；技术细节章前置一段"人话版"价值摘要。
10. **目录定制化**：按项目类型（大挑学术/大挑发明/小挑商业）套 1.1–1.4 的差异化骨架，目录标题体现项目特色数据（如"基于56村调研的XX模式判别"式命名法）。

### P2（锦上添花）
11. **答辩材料增强**：生成"评委预问清单"（按 7.2 三重验证分类）+ 回应公式模板（接住→证据→解法→优化方向）。
12. **质量门扩展**：把第 8 节反面模式做成检测词表/正则（"助力""赋能""国内领先""面临许多问题"等无数字绑定的高频空话），接入 quality_gate/export_guard。
13. **图表规范**：技术类文档强制配原理结构图+实测曲线；PPT 与 word 数据一致性自动校验。
