## 新增章 A｜核心创新点（建议插在原「九、产品特点与 AI 功能核心作用」之后）

本项目不是「又一个通用 AI 写作工具」，而是**把赛事评分标准翻译成可执行的生成约束，并让评委视角提前介入生成过程**。三处创新如下：

**A1 架构创新：不是单轮直出，而是「生成—评审—定向修订」的闭环**

不是让模型一次写完就交付，而是把规则解析、文稿生成、模拟评委、定向修订拆成可独立评测的节点，形成闭环。模拟评委按当前赛事的评分维度先行打分并指出具体章节的缺失，再由修订节点针对被点名的章节定点修补，而不是整篇推翻重写。这一闭环把「写完了才知道哪里不行」变成「写的过程中就知道哪里不行」。

**A2 知识库创新：不是通用语料，而是按赛事结构化的评分口径库**

不是把往届范文塞进检索库让模型模仿（那既涉及版权，也会导致撞车），而是按「赛事—赛道—评分维度」三层结构化沉淀官方规则与评分口径，让生成过程直接受规则约束。知识库只存规则与口径，不存参赛作品原文，从机制上规避版权与同质化风险。

**A3 功能体系创新：不是只出文稿，而是一次成型且互相引用**

不是单独生成一份申报书，而是把申报书、答辩问题、PPT 大纲、演讲稿、图表数据在同一套素材上生成，彼此引用同一组数字与结论。这解决了团队分开准备材料时最常见的「PPT 里的数字和申报书对不上」问题。

## 新增章 C｜风险分析与应对（插在新增章 B 之后）

**C1 技术风险**

- **依赖第三方大模型 API**：模型服务价格波动或接口变更会直接影响生成成本与稳定性。
  应对：模型调用层做统一封装，支持更换底层模型而不改动上层流水线；关键路径设置超时与降级，单次节点失败不阻断整体出稿。
- **AI 幻觉无法完全消除**：生成内容仍可能包含未经核实的数字或表述。
  应对：在数据层面强制标注来源类型（实测值 / 公开数据 / 测算值 / 设计目标值），禁止裸数字；同时提供「待替换数据清单」，把估算项集中列出提示人工复核。**本系统定位为辅助工具，最终提交内容须经团队人工复核**——这是本项目的明确边界，而非缺陷回避。
- **赛事知识库持续更新压力**：赛事规则每年调整，知识库滞后会导致生成内容偏离当年口径。
  应对：知识库按赛事分文件维护，规则变更时只更新对应文件；每次更新后跑一轮规则解析回归检查。

**C2 市场风险**

- **通用大模型入局**：若通用模型上线科创备赛插件，会分流部分浅层需求。
  应对：本项目的壁垒不在「会不会写」，而在「懂不懂评分口径」——赛事结构化知识库与模拟评委闭环需要逐赛事积累，通用插件短期难以覆盖多赛事差异化规则。
- **高校预算周期性波动**：B 端采购集中在特定时段，收入存在季节性。
  应对：C 端小额付费与 B 端机构授权并行，降低单一收入来源依赖。

**C3 运营风险**

- **用户增长与转化**：免费用户转化为付费用户的比例存在不确定性。
  应对：简洁版保留为免费入口承担引流，深度版承载付费；按首年渗透率分档做保守/中性两版预测（见商业模式章）。
- **并发与额度成本**：高峰期调用量上升会推高成本。
  应对：已设置并发上限与全局额度闸门（Semaphore 并发控制 + 全局额度配额），团队规模扩大时可提升额度或改为每人自带密钥。

**C4 内容合规风险**

- **用户上传涉密项目**：参赛项目可能含未公开技术细节。
  应对：用户数据隔离存储，不用于模型训练，提供本地删除入口。
- **生成内容版权**：生成物可能与其他选手表述相近。
  应对：内置同质化检测节点，在撰写前比对知识库往届方向并预警撞题，把问题消灭在成稿前。
- **AI 生成内容参赛伦理**：赛事对 AI 辅助的边界规定尚不统一。
  应对：产品明确定位为「辅助备赛工具」，输出物保留用户可追溯的修改痕迹，并提示用户遵守当届赛事的原创性规定。

## 新增章 E｜未来发展规划（插在新增章 D 之后，作为末章）

**短期（1 年内）**
- 赛事覆盖从当前主要赛事扩展至更多主流科创赛事，知识库按赛事补齐赛道与评分维度
- 补齐导出物的图表类型与版式模板，重点提升 PPT 与申报书图表的一致性
- 建立生成质量回归集，每次 Prompt 改动后跑固定样例比对

**中期（1—2 年）**
- 支持团队协同编辑与版本对比，适配多人备赛场景
- 增加指导老师视角：批量查看学生项目进度与生成质量
- 探索高校机构授权的标准化交付形态（部署方式、培训材料、后台管理）

**长期（2—3 年）**
- 把「按评分口径生成」的能力迁移到相邻场景（课题申报、学科竞赛、课程作业指导）
- 积累跨届赛事数据，形成可量化的「备赛质量基线」，为新用户提供对标参考

## 改写块 F｜市场空间（**替换**原「11.1 市场空间」）

原写法引用全球 AI 写作辅助软件大盘（53.57 亿美元），无法说明本项目所处细分赛道的真实空间。改为三层测算：

**TAM（总潜在市场）**
全国高等教育在学总规模约 4763 万人（公开数据，教育部口径，**年份需核实**）。按「每年参与各类大学生创新创业赛事的学生占比约 8%—12%」测算，TAM ≈ **380 万—570 万人/年**（测算值，基于参与率假设）。

**SAM（可服务市场）**
本项目首期覆盖 iCAN、挑战杯、互联网+、国创四类赛事。按这四类赛事在双创参赛人群中占比约 25% 测算，SAM ≈ **95 万—140 万人/年**（测算值，基于赛事结构占比假设）。

**SOM（首期可获得市场）**
按首年渗透率 0.3%—0.5% 测算，SOM ≈ **3000—7000 人/年**（测算值，基于新工具首年渗透率假设）。

> 口径说明：以上为「人数」口径而非「金额」口径，避免与软件大盘数据混淆；金额测算见商业模式章。三项测算的假设条件（参与率、赛事占比、渗透率）均需在提交前用真实调研数据替换。

## 改写块 H｜竞品多维对比（**替换/追加**到原竞品分析处）

原分析仅对比两款通用写作工具。补充为四类对象的多维矩阵，并补入「对手优势」与「壁垒维持」的客观讨论。

| 对比维度 | 本项目 | 秘塔写作猫 | 讯飞写作 | 通用大模型（豆包 / Kimi） |
|---|---|---|---|---|
| 赛事规则理解 | 高（按赛事解析评分维度） | 无 | 无 | 低（需用户自行写清规则） |
| 结构化赛事知识库 | 有 | 无 | 无 | 无 |
| 多智能体协同 | 有（解析/生成/评审/修订） | 无 | 无 | 无 |
| 同质化（撞题）预警 | 有 | 无 | 无 | 无 |
| 模拟评委打分 | 有 | 无 | 无 | 需用户自行构造 |
| 导出物完整度 | 申报书/答辩/PPT/演讲稿/图表 | 文稿 | 文稿 | 文稿 |
| 通用写作能力 | 弱于对手 | 强 | 强 | 最强 |

> 说明：上表为**自评口径**（测算/自评），用于说明定位差异，非第三方评测结论。

**客观承认的对手优势**：秘塔与讯飞在通用长文写作、语法润色、多语种方面的成熟度高于本项目；通用大模型的通用知识广度与交互灵活性本项目不具备。

**壁垒如何维持**：若通用大模型后续上线科创备赛插件，本项目依靠两点维持差异——一是逐赛事积累的结构化评分口径库（需按赛事人工维护，属长期积累资产），二是「生成—评审—定向修订」的闭环机制（不是单次问答能替代）。同时须持续补齐通用写作能力，缩小与成熟工具的体验差距。
