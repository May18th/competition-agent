# 科创赛事助手 导出物质量标杆（蒸馏版）

> 目标：让网站生成的所有提交物（申报书、路演PPT、答辩稿/答辩问题、申报材料模板、图表）持续对标网上高质量获奖作品。
> 来源：互联网+/挑战杯/iCAN 获奖申报书模板、金奖案例复盘、国赛路演高分实战手册、百场评委复盘、Helion360/Sequoia/Airbnb 顶级 Pitch Deck。

---

## 一、通用铁律（所有导出物）

1. **真实可溯源**：所有数字必须能说出来源——实测/官方/测算；测算必须写清假设；严禁编造机构/年份/型号。
2. **学生主体**：强调团队自主完成的工作；指导老师仅提供理论指导，不写挂名。
3. **盲审安全**：导出物默认不出现院校、导师、成员真实姓名；用「本项目团队」指代。
4. **一页/一节一核心**：不堆叠多个主题；标题本身就是结论。
5. **绝对化词汇黑名单**：行业第一、彻底解决、全球领先、颠覆式、独一无二等一律禁用。
6. **数据三分标注**：
   - 真实数据：正常写 + 来源。
   - 测算数据：写「测算：基于 XX 假设」。
   - 待补充：留空或放填写位，禁止用 `【待填写】` 占位符。

## 二、申报书（创业计划书/项目计划书）

### 2.1 标准结构（10-30 页）

| 章节 | 核心要求 | 避坑 |
|---|---|---|
| 封面+版权声明 | 项目名≤12 字、一句话定位、赛道/组别 | 不放多个 logo、不放目录 |
| 执行概要 | 300-500 字：痛点+方案+创新点+已验证结果+社会价值 | 不写「本文」「笔者」 |
| 市场痛点分析 | 案例/报道/故事引入+原因逐条分析+市场规模 | 禁止「行业普遍存在」空话 |
| 产品与解决方案 | 技术实现方案+产品图片/流程图+产品优势 | 不写具体型号除非实测提供 |
| 竞品分析 | 可量化对比表（性能/价格/准确率/成本） | 不捏造对手、不贬低 |
| 商业模式 | 商业模式图+盈利模式+单位经济 | 不为比赛编假模式 |
| 运营现状 | 专利/客户/成交额/带动就业/媒体报道 | 只展示相关成果，不重复 |
| 营销策略 | 目标客户→推广策略→产品策略 | 三步走，具体可落地 |
| SWOT/风险 | 客观分析，一个风险对应一个措施 | 不形式主义、不回避 |
| 财务数据 | 3 年财务预测+融资需求+资金用途 | 不凑整数/等差等比 |
| 团队介绍 | 成员分工+实质性贡献；导师研究专长 | 盲审匿名化 |
| 未来计划 | 6 月/1 年/2 年具体目标与手段 | 不写 3-5 年空规划 |
| 附录附件 | 证书、专利、调研数据、产品图片 | 图片配简短说明 |

### 2.2 写作规则

- 执行概要第一句必须点明「服务对象+核心问题+核心手段」。
- 痛点用真实场景/数据引入，分析深入客观。
- 技术方案必须配框架图/流程图，说明「用什么技术、实现什么功能、解决什么问题」。
- 每个数字必须可溯源；市场规模做 bottom-up 估算，写清口径。
- 财务预测合理客观，利润率、增长率符合行业规律。

## 三、路演 PPT

详见 `docs/路演PPT设计标杆_蒸馏版.md`。核心摘要：

- **8 页压缩版**：封面→痛点→解决方案→数据/Traction→竞争壁垒→商业模式→团队里程碑→愿景。
- **设计系统**：16:9、12 列栅格、4 主色+1 数据强调色、固定字号层级。
- **内容密度**：每页 ≤100 字、≤6 行、≤5 要点；标题即结论。
- **必须出现**：真实产品截图/流程图、大数字指标卡、2×2 竞品矩阵或雷达图。
- **结尾页**：不写「谢谢聆听」，写一句话定位+3 条核心价值+明确下一步。

## 四、答辩稿与答辩问题

### 4.1 路演稿时间分配（5-8 分钟版）

| 模块 | 时长 | 高分逻辑 |
|---|---|---|
| 开场 | 10-15s | 一句话定位+核心数据钩子 |
| 痛点 | 30-40s | 行业现状+短板+用户痛点+市场空白，结合调研 |
| 方案 | 50-60s | 不讲原理堆砌，只讲解决方式、核心功能、落地场景 |
| 核心创新与壁垒 | 50-60s | 创新点+佐证支撑+差异化优势，杜绝伪创新 |
| 落地成果 | 50-60s | 量化数据+真实案例+长效价值，证据链完整 |
| 团队与规划 | 30s | 学生主导+跨学科分工+具体贡献 |
| 结尾 | 10s | 回归一句话定位+3 条核心价值+明确下一步 |

### 4.2 问答回答框架

1. **先一句话给结论**。
2. **按证据链展开**：实测数据、对比基线、来源口径、样本量与误差范围。
3. **主动堵质疑**：指出最弱假设、最大风险与结论边界。
4. **区分实测/估算/预测**，不现场编造。
5. **盲审不报院校/导师/成员真实姓名**。

### 4.3 高频答辩问题（必须预生成）

- 请用一句话讲清楚你们是做什么的？
- 项目的核心壁垒是什么？凭什么别人做不了？
- 你们面临的最大风险是什么？怎么应对？
- 为什么是你做这件事？
- 目标用户是谁？市场有多大？
- 有没有付费验证？用户反馈怎么样？
- 一句话概括你们的技术优势？
- 和竞品相比，哪些指标上有明确优势？
- 你的 AI 在哪个环节不可替代，去掉 AI 还成立吗？
- 数据来源是哪里？是否可复现？
- 专利/软著什么时候申请，第一发明人是谁？
- 第一年的营收怎么预测出来的？
- 融资的资金主要用到哪里？
- 团队如何分工？每人具体做了什么？

## 五、申报材料模板

模板必须预留真实数据位，并给出填写示例与来源标注示例：

```markdown
【市场规模】
- 数据：____ 亿元（来源：____ 机构 ____ 年报告 / 测算：基于 ____ 假设）

【运营成果】
- 已服务用户/客户：____ 人/家（来源：平台后台 / 合同 / 实测）
- 成交金额：____ 元（来源：财务系统 / 测算）

【团队分工】
- 成员 A：负责 ____，已完成 ____（盲审用「成员 A」而非真实姓名）
```

- 社科类重调研报告真实性：须扎根中国大地做实证（问卷/访谈/田野），样本量、地域分布、信效度明示；重学术规范性（参考文献/数据三角验证）。
- 科技发明制作类重「发明点」与「实物/样机成熟度」：须点明与现有技术区别特征（对比表：功能/成本/效率）；不重商业计划书式财务，重「社会效益/学术价值/应用前景」三性。
- 导出物须替换「三情景财务」为「应用前景+推广路径+社会/学术效益」写法；社科类附调研方法章与样本说明，科技类附发明点对比表与样机状态。

### 11.2 国创 结题/中期 结构与过程性证据（对应弱项：国创仅在第5权重/结题提及）
- 重「过程性」：立项依据→研究内容→技术路线→阶段成果→经费使用→问题与上一步，逐学期/逐月记录。
- 结题须附「成果清单」（论文/专利/软著/竞赛获奖/实物）标状态（呼应 V4.3 佐证四件套）；经费按预算科目列支比例（设备/材料/差旅/出版，呼应 V4.4 成本结构%但更重合规）。
- 重「学生主体性」：成员实质贡献可指认（对应章B 团队可核验），禁导师代劳表述。

### 11.3 跨赛事「证据链一致性」铁律（强化 V4.3，新增生成期门禁）
- 申报书/路演PPT/答辩稿 三处同一指标（市场规模/营收/准确率/降本%）必须完全一致，国赛评委常跨材料比对，不一致即扣真实性分。
- 每个关键数字带来源标签：实测(测试条件+样本量) / 估算(测算假设) / 预测(乐观-中性-保守区间)，禁裸数字。
- 方案章承诺效果须在佐证章/数据页回扣同一数字与来源，形成闭环。生成器导出前须做跨文件数字一致性校验。
