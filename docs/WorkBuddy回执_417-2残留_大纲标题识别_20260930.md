# WorkBuddy 回执 · 417-2 残留修复：文档级大纲标题识别

- 时间：2026-09-30 14:2x (GMT+8)
- 执行：WorkBuddy（W）
- 改动文件：`/opt/comp-agent/rich_pipeline.py`（`_outline_deck`，备份 `.bak.20260930_outline`）
- 生效方式：`systemctl restart comp-agent`

## 问题
`_outline_deck` 跳过文档级标题的旧判据：
```python
if re.match(r"^(?:PPT|路演)?\s*大纲$|^目录$", title, re.IGNORECASE):
```
只认**绝对等于**「大纲 / PPT 大纲 / 路演大纲 / 目录」。
实际 LLM 产出的大纲常写成「**智能巡检系统 · 3分钟路演大纲**」「**项目PPT大纲（16页）**」——
这类带前后缀的文档标题**匹配不上**，于是被当成**一页正文** → PPT 页数 +1、
大纲↔PPT 对不上，正是 417-2「页数与大纲不一致」投诉的触发场景之一。

## 修复
去符号空白后**以「大纲」结尾**（允许 PPT/路演 前缀、括号页数后缀）或等于目录类 → 判为文档级标题跳过：
```python
_norm = re.sub(r"[\s\u00b7\-\u2014_()（）\[\]【】]+", "", title)
if re.search(r"(?:PPT|路演)?大纲(?:\d+页?)?$", _norm, re.IGNORECASE) \
        or _norm in ("目录", "PPT目录", "目录页"):
    continue
```

## 服务器端实测（.venv/bin/python3，非靠猜）
| 大纲写法 | 期望页数 | 实际 | 结果 |
|---|---|---|---|
| `# 智能巡检系统 · 3分钟路演大纲` + 3 章节 | 3 | 3 | OK |
| `# 项目PPT大纲（16页）` + 2 章节 | 2 | 2 | OK |
| `# PPT 大纲` + 2 章节（回归） | 2 | 2 | OK |
| 无文档级标题 + 3 章节（回归） | 3 | 3 | OK |
| 带空格路演大纲 + 2 章节 | 2 | 2 | OK |

**已知 trade-off**：若真实章节页标题本身以「大纲」结尾（如「2. 方案大纲」）会被一并跳过（实测 3→2）。
此类章节命名极罕见，且相比"文档标题被算成一页导致整体错位"，跳过风险更低，故接受。
