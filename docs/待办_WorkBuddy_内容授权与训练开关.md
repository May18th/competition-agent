# 待办 · WorkBuddy · 第一百七十四轮（内容使用授权 + 训练开关）

> 后端已就绪：`POST /api/training/archive`（验证产物入库，含 `consent` 参数）和 `GET /api/training/stats`（训练库统计）。
> 本文件只交接前端活，后端接口由 Codex 已完成并提交。

## 背景

174 轮「验证即沉淀」：验证中通过质检的高质量生成物，脱敏后回流入知识库用于训练。前提是**用户知情 + 可拒绝**（合规）。

## 要求（前端）

1. **设置项开关**：在个性化板块（141 轮位置）加「我的生成内容用于训练」开关，默认**开**、可关；关闭后新生成不再入库。开关状态随用户记忆（localStorage，沿用现有记忆机制）。

2. **首页/设置授权条款**：加一句「内容使用授权」说明，明确：生成内容可**匿名化（脱敏）后用于知识库沉淀**，用户可随时关闭。放进现有隐私说明（149 轮）同页即可，不用单独成页。

3. **触发入库的时机（给用户看的入口）**：结果页/历史里，对「评分≥85 且质检通过」的记录给一个「加入训练库 / 沉淀为范文」按钮（或标记可入库），点击后调后端接口。

## 后端接口（前端对接用）

### `POST /api/training/archive`
- 入参 JSON：`{"history_id": 123, "consent": true}`
- `consent=false` → 返回 `403 {"error":"用户未授权内容入库（已在设置中关闭）"}`
- 评分 <85 → 返回 `422 {"code":"score_low","score":X,"error":"评分 X < 85，未达到入库门槛"}`
- 成功 → `{"success":true,"id":样本id,"is_new":true/false,"score":85}`

### `GET /api/training/stats`
- 返回 `{"success":true,"总份数":N,"by_competition":{...},"by_type":{...}}`

## 验收（豆包会查）

- 开关默认开、可关、状态随记忆。
- 关闭后调 archive 返回 403。
- 首页/设置可见授权条款。
- 评分 <85 的记录点「加入训练库」会被拒并提示。

## 注意

- 前端**不要**自己写脱敏逻辑，后端 `desensitize_text` 已处理（电话/邮箱/身份证/学号/「负责人：某某」/「XX大学」）。已知盲区：自由文本里的裸姓名（如「张三」无角色标签）脱不掉，别在文案里宣传「全自动脱敏」。
