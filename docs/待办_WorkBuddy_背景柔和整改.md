# 待办（WorkBuddy）· 背景「割裂」整改（用户反馈，最高优先）

> 用户原话：「你不觉得背景很割裂吗」。要求：默认第一次进页面要柔和舒服、不刺眼；各种特色背景仍可选（右上角「背景」8 预设 + 上传已实现，勿动）。

## 根因诊断（Codex 已读 static/style.css 实测）
浅色背景不是「一整块柔和的底」，而是由多组独立彩色元素拼起来的，色块感强、不连贯，所以看着「割裂」：

1. 三个大光球 `.wb-orb-1/2/3` 分居三角：青 `rgba(34,211,238)` 左上、紫 `rgba(168,85,247)` 右上、蓝 `rgba(59,130,246)` 底部，各 480~600px 大圆。浅色下 `body.light .wb-orb{opacity:.18;filter:blur(96px)}`，透明度仍偏高，三个彩色大圆边界还能看出来。
2. `.wb-grid` 48px 网格线（浅色 `rgba(60,80,150,.055)`）覆盖中心、边缘 mask 淡出，形成「中心有纹理、四周空」的分区感。
3. `.wb-bg` 里又叠了 3 团径向柔光（靛/青/紫），与光球/网格重复，层次叠太多。

## 修复方向（目标：第一眼是干净的柔和白，仔细看才有一两处极淡色彩）
1. **底色为主**：`body.light .wb-bg` 只保留一条柔和纵向渐变 `#ffffff → #fbfcfe → #f4f7fb`，去掉/大幅弱化那 3 团柔光（或只留 1 团，透明度 ≤.05）。
2. **光球降噪**：`body.light .wb-orb` opacity 从 `.18` 降到 `.06~.09`，或直接隐藏 1~2 个、只留 1 个极淡光球点缀；饱和度往灰蓝降。
3. **网格淡出**：浅色下 `.wb-grid` 降到 `.03` 左右或直接隐藏（白底上网格线易显脏）。
4. **去分区感**：`body.light .wb-bg::after` 的深色值保持极低（现 `rgba(15,23,42,.035)`，可降到 `.02`），不要出现「中心亮、四周明显暗」的边界。

## 验收
- 桌面 + 移动端首次进页面：干净柔和，无明显色块分界/斑块，不刺眼。
- 细看有一点点层次（不是死白一片），但绝不「割裂」。
- 切夜间（body.dark）仍正常；右上角自定义背景功能不受影响。
