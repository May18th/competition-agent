## 问题（豆包 P0-1「无目录」投诉的真凶）
`build_docx` 原逻辑：
```python
if toc and len(正文去空白) < 2500:
    toc = False
```
→ 导出**简洁版 / 偏短说明书**时目录被**静默关闭**（封面仍在），用户拿到「有封面无目录」。
前序回执把 417-1 判为「代码已具备、非缺陷」，但没处理这个阈值，故投诉场景仍在。

## 修复
有封面的正式文档（cover=True，如 default/report 申报书）改按**章节数 >=3** 出目录，
不再受 2500 字限制；无封面的简洁文档保留字数阈值，避免目录页大半空白。

```python
if toc:
    _plain_len = len((text or '').replace('\n', '').replace(' ', ''))
    _h_cnt = 0
    for _b in blocks:
        if _b[0] == 'h' and _b[1] <= 3:
            _h_cnt += 1
    if not (cover and _h_cnt >= 3) and _plain_len < 2500:
        toc = False
```
