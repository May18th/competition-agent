# 待办_WorkBuddy_趣味性增强（反馈态 + 赛事图标）

> 来源：Codex 方案（2026-09-28）
> 对象：WorkBuddy（index.html 归你）
> 优先级：P3（可选，非核心区，克制）

## 核心原则

只加在「反馈状态」和「赛事识别」这类非核心区；正文 / 表单 / 导出 / 评分权重一律不加。

## 要做（四个小点）

1. **空状态**：历史面板为空 / 尚未生成时，给一句有温度的话，如「✍️ 还没有生成记录，去试试第一篇吧」。
2. **失败/错误状态**：生成失败 / 导出失败时，提示带一点同理心，如「😅 这次没生成成功，可能是网络抖了一下，换个创意或稍后再试」。
3. **成功反馈 toast**：导出 / 生成完成时带小 emoji，如「📦 已打包，去下载吧」「🎉 三件套已生成」。
4. **赛事固定 emoji 图标（最推荐，趣味 + 实用）**：给 15 个赛事各配一个固定小 emoji，放在下拉选项和结果头部，作为视觉锚点、帮助快速识别。参考映射：
   - iCAN 🚀 / 互联网+ 🌐 / 大挑 🏆 / 小挑 💼 / 国创 🎓
   - 数模 📊 / 电设 ⚡ / 西门子杯 🏭 / 计算机设计 💻 / 蓝桥杯 ⌨️
   - RoboMaster 🤖 / 信息安全 🔐 / 服务外包 🧩 / 广告艺术 🎨 / 金砖 🔗

## 明确不加

- 结果正文、评分权重、表单等核心区；
- AI 评委打分配 emoji 反应；
- 满屏装饰、GIF、音效。

## 验证

- 空 / 失败 / 成功三种反馈状态有温度、有 emoji；
- 赛事下拉和结果头部有固定 emoji 图标，正文和导出无新增 emoji。
