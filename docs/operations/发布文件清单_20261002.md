# 发布文件清单（2026-10-02）

本文只描述“代码发布”范围，不执行上传、不包含用户运行数据。本地目标入口是
`backend/wsgi.py` -> `backend/app.py`，本地开发入口是 `backend/run.py`。两者都会把工作目录固定到
`backend/`。线上当前入口尚未通过 SSH 只读探测确认，发布前必须先确认远端服务是否已经迁移到
该布局；不能仅凭本地目录名推断线上路径。

## 必须发布

### 前端

```text
frontend/index.html
frontend/科创赛事助手.ico
frontend/static/*.css
frontend/static/*.js
frontend/static/*.json
frontend/static/*.png
frontend/static/*.ico
```

当前正式静态资源是：`app.js`、`style.css`、`competition_index.json`、`notice.json`、
`marked.min.js`、`purify.min.js`、`echarts.min.js`、正式 logo/favicon/og-image/icon 图片。
`frontend/static/` 只能按正式扩展名清单同步，不能直接把整个目录递归打包。

### 后端代码和依赖

```text
backend/*.py
backend/requirements.txt
backend/Procfile
backend/Dockerfile
backend/scripts/render.yaml       # 使用 Render 时需要
backend/wsgi.py
```

`backend/*.py` 目前包含主入口、生成/导出器、质检、知识检索和消息编排模块。动态导入的
`agent_orchestrator.py`、`chroma_retriever.py`、`llm_factory.py` 也必须存在；因此发布前要确认
它们已在本地工作树中，而不是只同步已提交文件。

### 后端只读知识源

```text
backend/data/*.txt
backend/data/competition_profiles.json
backend/data/event_requirements.json
backend/data/README_知识库提交规范.md
backend/knowledge_base/*.json
backend/knowledge_base/*.txt
```

这些文件被 `competition_agents.py`、`competition_rules.py`、`rich_pipeline.py` 和
`chroma_retriever.py` 直接读取。缺失会导致赛事匹配、规则解析、图表证据或生成质量降级。

## 明确禁止发布/覆盖

以下路径是远端运行数据、凭据或临时产物。部署脚本应保留远端版本，不能用本地同名文件覆盖：

```text
backend/competition.db
backend/data/official_docs.json
backend/data/vulns.json
backend/.env
backend/.uid_secret
backend/.admin_users.json
backend/quota.json
backend/uploads/
backend/generated/
backend/tmp_export/
backend/chroma_db/
backend/训练库/
frontend/static/tmp_*.html
frontend/static/tmp_*.png
frontend/static/tmp_*.json
*.log
```

`official_docs.json` 虽然位于 `data/`，但由用户上传的赛事资料写入；它不是可随代码覆盖的
静态知识源。`chroma_db/` 可由 `chroma_retriever.py` 根据 `data/*.txt` 首次运行时重建，避免
把机器相关的向量索引和旧数据带到另一台服务器。

## 对 `deploy_safe.sh` 默认列表的审计

当前默认值是：

```text
frontend/index.html frontend/static/* backend/*.py
```

结论：**不完整且过宽**。

1. 漏发 `frontend/科创赛事助手.ico`、`backend/requirements.txt`、`backend/data/*`、
   `backend/knowledge_base/*` 以及部署描述文件；新服务器或刚重建环境会缺规则、知识库和依赖。
2. `frontend/static/*` 会把 `tmp_*.html` 等本地探针一起上传，增加缓存污染和不必要的发布内容。
3. `backend/*.py` 会覆盖全部顶层 Python（其中有探针/维护脚本），不会泄露密钥，但不利于审计。

在实际发布前，先用收紧后的默认列表做本地预演；如需审计或固定发布范围，也可以显式传入下面的同等文件模式：

```bash
bash backend/scripts/deploy_safe.sh --dry-run --files \
  "frontend/index.html frontend/科创赛事助手.ico \
   frontend/static/*.css frontend/static/*.js frontend/static/*.json frontend/static/*.png frontend/static/*.ico \
   backend/*.py backend/requirements.txt backend/Procfile backend/Dockerfile \
   backend/data/*.txt backend/data/competition_profiles.json backend/data/event_requirements.json \
   backend/data/README_知识库提交规范.md backend/knowledge_base/*.json backend/knowledge_base/*.txt"
```

`--dry-run` 输出应逐项检查，确认列表里没有 `competition.db`、`uploads`、`generated`、
`tmp_export`、`.env`、`.uid_secret` 或 `official_docs.json` 后，才可移除 `--dry-run`。部署
依赖时另行在远端执行 `python -m pip install -r backend/requirements.txt`，不要把虚拟环境目录
或本地 `chroma_db` 一起传输。当前脚本已将 `--dry-run` 放在 SSH 和远端 `pre_backup` 之前，
所以预演会在本地展开并列出文件，不连接远端、不创建备份、不传输、不重启。

## 发布前快速检查

```powershell
# 只列出候选文件，不上传
Get-ChildItem frontend/static -File |
  Where-Object { $_.Name -notlike 'tmp_*' } |
  Select-Object -ExpandProperty FullName

# 确认敏感/运行期文件不会进入手工清单
rg -n "competition\.db|official_docs\.json|uploads|generated|tmp_export|\.env|uid_secret|admin_users|chroma_db" \
  docs/operations/发布文件清单_20261002.md backend/scripts/deploy_safe.sh
```

本清单只用于同步前核对，未执行任何远程操作，也不代表线上已经更新。
