## 四、拿到包怎么跑

```bash
# 1. 依赖（Python 3.10+，生产为 3.10.12）
pip install -r requirements.txt

# 2. 模型密钥（二选一，DeepSeek 为主）
echo 'DEEPSEEK_API_KEY=sk-xxx' > .env
# 备选：CLAUDE_API_KEY（火山引擎适配）

# 3. 启动
python run.py                 # 开发：http://127.0.0.1:8080
# 生产：
gunicorn wsgi:app --bind 127.0.0.1:8080 --workers 1 --threads 24 --timeout 600
```

**首次启动会自动建库建表**（`backend/.data/competition.db`），不需要手工迁移脚本。

无密钥时页面可浏览、历史可看，生成与对话接口返回明确错误——不会白屏。

### 三条硬约束（不是偏好，是设计前提）

1. **必须 `workers=1`**。任务表、并发计数、限流桶都在进程内存，多 worker 会各算各的：任务查不到、限流失效。
2. **不能只读文件系统**。生成过程要写 `.data/`，无写的环境（如 Vercel Serverless）能启动但生成必失败，详见 `docs/部署说明.md`。
3. **中文字体必须装**。Linux 上不装 `fonts-noto-cjk`，导出的图表与 PPT 中文全是方框（`Dockerfile` 已处理）。

## 六、三条"别删"（都踩过或差点踩）

| 对象 | 为什么不能删 |
|---|---|
| `frontend/` | **这是生产目录，不是历史遗留**。`app.py` 的 `FRONTEND_DIR` 与 Flask 的 `static_folder` 都指向它；删了首页与所有 `/static/*` 立刻 500 |
| 根目录 `deploy_aliyun.sh` | `docs/部署说明.md` 的一键部署命令按仓库根路径取用 |

另外：`backend/app.py` 根目录有几个 `tmp_export*` 运行时工作文件（导出暂存），**不是垃圾，不能清理**——代码里按固定路径读写它们。

> **服务器上另有一批同名文件，不属于本包**：`/opt/comp-agent/static/` 下有 12 个 `wb*.js`（wbconst / wbnavig / wbpage 等），首页不引用，但**线上 `sw.js` 仍是旧版预缓存清单，逐个列了它们**。在服务器上删除会让在线 PWA 预缓存 404、安装失败。本包内的 `sw.js` 已换成自毁版（清缓存并注销自身，无预缓存清单），所以包内只有 `wbchat.js` 一个 wb 系列脚本。

## 七、与线上的关系

| | 本地仓库（本包） | 线上部署 |
|---|---|---|
| 布局 | `backend/` 包结构 | 扁平结构（`/opt/comp-agent/app.py`） |
| 入口 | `run.py` / `wsgi.py` | `gunicorn wsgi:app` |
| 前端 | `frontend/` | `/opt/comp-agent/static/` + 根 `index.html` |
| 代码同步 | — | **逐项移植，不整包覆盖** |

线上与本地是两套血缘：行尾不同（index.html/app.js 为 LF，style.css/competition_agents.py 为 CRLF）、行为有差异、部分模块只存在于一侧。整文件覆盖会丢改动，历史上出过一次"双向覆盖"事故。移植纪律见 `docs/部署说明.md`，工具用 `scripts/deploy_static.sh`（基线 md5 比对 → 服务器备份 → 传 /tmp 再 cp → 回读校验）。

## 八、打包（可复现）

交付用的源码包直接由 git 提交生成，只含被跟踪的文件，天然不含运行产物与密钥：

```bash
git archive --format=zip --prefix=competition-agent/ \
  -o competition-agent-src-$(date +%Y%m%d).zip HEAD
```

本次产物：`competition-agent-src-20261125.zip`，228 个文件、压缩后 3.0 MB（原始 5.5 MB）。
md5 会随提交变化，打包后自行 `md5sum` 记录并与交付登记表对齐即可——不要在文档里写死，否则改一行文档就对不上了。

不要用「右键压缩整个目录」的方式打包——那样会把 `.workbuddy/`、`backend/.data/`、
`backend/archive/`（历史归档）、`artifacts/`（验收截图）和 `.env` 一起带进去，
包会从 5.5 MB 涨到几十 MB，并且泄露密钥。
