# 科创赛事多智能体协同创作助手

## 一、项目介绍
面向大学生科创竞赛团队的端到端多智能体系统，基于 Flask 开发，实现赛事规则解析、创意同质化检测、申报书智能生成/优化、模拟评委评审全流程自动化，降低学生参赛门槛。

## 四、运行流程图
```
用户输入
  ↓
选择比赛 → 输入项目创意/上传申报书草稿 → 选择简洁版/深度版
  ↓
📋 规则解析智能体：读取赛事知识库，提取评分标准
  ↓
🔍 同质化检测智能体：检索往届项目，评估撞题风险
  ↓
✍️ 文稿生成智能体：生成/优化申报书（简洁版 2000~4000 字级 / 深度版 12000 字级）
  ↓
⚖️ 模拟评委智能体：打分，指出问题，给出改进建议
  ↓
结果展示 → 导出中心导出 Markdown/Word/PPT/PDF/ZIP 文件

> 深度版另有多路分析智能体（竞品、商业模式、风险、技术方案、实施计划、社会价值、项目简介）并行产出，再汇总成完整申报书；各环节能并行则并行，缩短出稿时间。
```

## 五、技术栈
- 后端：Python 3.10 + Flask + 多智能体编排
- 模型：DeepSeek 大模型（可配置）
- 数据：本地txt知识库 + SQLite
- 前端：原生HTML/CSS/JS，响应式设计
- 部署：本地运行 + cpolar内网穿透

## 七、安全架构
> 数据隐私与后台安全为本项目重点整改项（安全测试 50+ 项闭环修复）。以下各项均为**代码层已实现**，验收结果来自本地实测；公网复测随部署完成后由豆包验收。

1. **统一鉴权（登录门 + fail-closed）**：后台/管理路由统一走 `_require_admin` + 全局 `_admin_guard`，覆盖 /admin /monitor /api/admin/* /api/kb/* /api/distill* 等全部管理面；未配置口令时默认拒绝（fail-closed），杜绝「未配置即开放」裸奔。验收：无凭证访问管理路由全 401，正确口令 200。

2. **登录会话（防爆破）**：`POST /api/admin/login` 校验口令，成功写 HttpOnly + SameSite=Strict 签名 cookie（8 小时有效）；连续 5 次失败锁定 15 分钟。验收：错口令 401、对口令 200 + set-cookie、带会话 200、无会话 401。

3. **数据隔离（匿名 uid 归属）**：历史/反馈/导出按 comp_uid cookie 归属过滤，`load_history` 只返回本人记录，`export_all` 只导出本人最新记录。验收：无 cookie / 伪造 cookie / 他人 cookie 均只能看到自己（或空）。

4. **传输加密（TLS1.3 + 后量子混合）**：公网走 Cloudflare 边缘 TLS 终结，启用 TLS1.3 + 后量子混合密钥交换（ML-KEM/X25519）。验收：curl -v 确认证书链为 Cloudflare（答辩前实测截图）。

5. **HSTS 强制 HTTPS**：全站响应头 `Strict-Transport-Security: max-age=31536000; includeSubDomains`。验收：curl -sI 可见该头。

6. **审计日志**：后台登录事件记录时间/IP/是否演示态，写 docs/后台审计.md（不入 git，防 IP 泄露）。验收：登录后审计文件有记录。

7. **评委演示只读模式**：独立演示口令（DEMO_TOKEN）登录即只读，写操作（蒸馏/删除/上传等）一律 403。验收：演示会话 GET 200、POST/DELETE 403。
