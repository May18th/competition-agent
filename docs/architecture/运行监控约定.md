# 运行监控约定（三方共同遵守）

> 范围：科创赛事助手（https://kechuang2026.cn/）及其服务器（8.149.236.90）。
> 原则：**发现异常必须记录 + 汇报，不留死角、不默认"别人会处理"。**

## 监控项

1. 网站可访问性：首页、/api/health 是否正常返回
2. 生成功能：简洁版/深度版能否正常生成（生成失败率异常升高）
3. 接口新字段：stage_label / pct / partial_content / scores / retryable 是否按指令上线
4. 服务器：磁盘（<80%）、内存（可用<200MB 告警）、gunicorn 进程、nginx 错误日志
5. 域名/证书：HTTPS 可访问、证书到期（2026-12-28）
6. 共享目录：是否有新指令/产物需要认领

## 异常记录格式（追加到本目录《运行日志.md》）

```
- 时间：YYYY-MM-DD HH:MM
- 现象：什么挂了/什么不对（带接口返回或报错）
- 影响：影响谁、影响什么功能
- 处理：已做什么 / 建议谁处理
- 记录人：豆包 / WorkBuddy / Codex
```

## 汇报规则

- 发现异常：记录到运行日志 + 在各自会话/群里明确汇报，不吞不拖
- 一切正常：定时查验汇报"查验正常"即可，不必每条都记
- 严重问题（全站打不开/生成全挂）：立即记录并汇报，不等定时任务
