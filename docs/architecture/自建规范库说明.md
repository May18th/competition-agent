# 自建规范库说明（第一百五十五轮 · skill 能力蒸馏）

## 结论
系统不调用任何外部 skill/插件（151/154 轮已实证：app.py / competition_agents.py 无 skill 调用，requirements 无插件依赖，架构自包含）。通用 skill 的实用能力已蒸馏为**自建规则/知识库**，价值与所有权归本系统。四条生成/质检链路均由自建规范驱动，映射如下：

## 四链路 → 自建规范源

1. **写作规范**（writer Agent 遵循）
   - 位置：`competition_agents.py` 写作 prompt（约 700–760 行的「硬性」约束 + `_SELF_TECH_HIGHLIGHTS`）
   - 内容：章节完整、每段有信息量、禁编造人名/日期/型号/机构引用、数据只准「真实值/测算值/示例值」且标明口径、禁【】占位符、团队只写「角色+职责」。

2. **质检规范**（L1–L6 质检闸门）
   - 位置：`quality_gate.py`
   - 内容：L1 生成完整性 / L2 导出检查（docx/pptx/pdf/zip）/ L3 套话·双盲 / L4 历史富媒体 / L5 版本号 / L6 评价真实性；`score_export`（≥85 + 一票否决）导出评分门；`check_depth` 空话段落防凑数（深度/简洁两档）。

3. **评审规范**（judge / expert_review 遵循）
   - 位置：`data/competition_profiles.json`（评分维度与权重，以官方规则为准）+ `competition_agents.py` 评审 prompt
   - 内容：维度/权重取官方、去掉写死区间、客观公正（高分有亮点、低分有硬伤、重点摊开零废话）、输出固定 disclaimer「模拟评审·非真人评审」。

4. **PPT 生成规范**（ppt Agent 遵循）
   - 位置：`pptx_builder.py`
   - 内容：15 套主题 + 7 种版式（封面/章节/要点/图表/表格/数据/结尾）+ 微软雅黑（含 east-asian）+ 统一页眉强调条与页脚。

## 独立性声明
- 以上四类规范均为**自建规则与知识库**，非外部 skill/模板调用；底层仅依赖基础库与 LLM API。
- 后续新增能力仍按「吸收通用能力 → 沉淀为自建规则/知识库」路径，不引入外部 skill 依赖。
