# 可创无限产品 PRD 基线

## 目标

帮助竞赛团队把真实的创意、草稿、数据和赛事要求整理成可编辑、可核验、可导出的申报材料。产品价值是减少整理和反复排版工作，不是替用户编造项目事实。

## 用户与场景

| 用户 | 主要任务 | 成功标准 |
|---|---|---|
| 参赛团队 | 提交创意或草稿，补充必要事实 | 少填字段即可得到结构完整的可编辑草稿 |
| 评委/演示者 | 快速查看完整样例和证据链 | 一键演示、来源清楚、导出物可打开 |
| 管理员 | 监控生成、失败、反馈和质量 | 按任务查看详情，可定位、重试、统计 |

## 核心输入

- 赛事名称或赛事规则文件
- 项目创意，或已有申报书草稿
- 用户主动提供的团队、预算、测试、市场和进度数据
- 可选的参考材料与版权授权信息

## 核心输出

- 申报书源文档（Word）
- 基于同一源文档转换的 PDF
- 约 8 页、内容密度合格的路演 PPT
- PPT 大纲、答辩问题、诊断意见和待核实数据清单
- 可追踪来源和生成任务日志

## 关键约束

1. 无来源具体数字必须标为测算或待核实。
2. 不展示“100%保证”等无法证明的绝对表述。
3. 待核实数据可以局部替换，替换正文后同步更新图表和导出物。
4. 生成中必须显示阶段和已完成片段，禁止重复点击创建任务。
5. 失败由系统记录、自动重试或保留已有片段；用户只看到可理解的处理状态。
6. 所有导出物从同一结果快照读取，不允许各自重新生成互相矛盾的内容。

## 验收场景

- 只填写创意：能生成简洁版完整可用结果。
- 上传草稿：以草稿为源进行结构化改写，并支持局部修改。
- 深度生成二次执行：不丢失图表、答辩、诊断和 PPT 大纲，不重复标题。
- 任意待核实数据替换：正文、表格、图表、Word/PDF/PPT 均同步。
- 模型超时或导出失败：记录原因，自动重试；仍失败时保留片段和可导出的已有结果。
- 桌面端与移动端：相同任务 ID、结果版本、数据和来源。
