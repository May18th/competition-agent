# 夜间模式色板优化方案（255.4·豆包自查交付）

目标：夜间模式不再刺眼、高饱和、深色重压；符合用户视觉偏好（白底柔和点缀、简洁不刺眼、避免深色高饱和渐变）。

## 问题实锤（真机体验）
- 生成等待页固定深色不随主题（255.2 附项）
- FAB 日间白字透明底不可见（255.2 附项）
- 夜间色板高饱和（当前默认背景为深紫蓝科技感图案，文字对比与卡片层次观感压迫）
- 用户原话：「夜间页面内容看起来很难受」「视界效果真的体验了吗」「颜色对比太差了，看着很难受」

## 推荐夜间色板（替换方案，供 WorkBuddy 实施）

| 用途 | 现（刺眼） | 建议 |
|---|---|---|
| 页面底色 | 深紫蓝 #1a1440 / #0d1b3e | 低饱和深蓝灰 #0f172a |
| 卡片/面板 | 深紫渐变 | #1e293b（纯色，无渐变） |
| 文字主色 | 亮紫白 | #e2e8f0 |
| 文字次色 | 霓虹蓝 | #94a3b8 |
| 主点缀色 | 高饱和青 #22d3ee | 柔和青蓝 #38bdf8（降饱和） |
| 强调色（CTA） | 紫渐变 | 纯色 #3b82f6（去渐变） |
| 边框/分隔 | 亮紫 | #334155 |
| 成功/评分色 | 荧光绿 | #4ade80（降饱和） |
| 阴影 | 无 | rgba(0,0,0,0.25) 柔和投影 |

## 实施要点
1. 全局 CSS 变量化（--bg/--card/--text/--accent…），一处定义全站生效
2. 等待页、FAB、弹窗、历史弹窗、后台登录/总览/数据面板/动态监视全部走变量，不写死深色
3. 深色背景不叠加高饱和渐变；装饰图案降透明度（≤0.15）
4. 日间保持白底柔和点缀（现状基调保留）
5. 背景预设 8 套（255.3）：全部为低饱和、可读性优先；用户自定义上传背景强制加浅色遮罩保证文字可读

## 验收标准（豆包复测）
- 切夜间：等待页/FAB/弹窗同步变色；无霓虹渐变；正文对比度≥4.5:1
- 切日间：FAB 文字可见；页面无刺眼
- 背景切换：8 预设差异明显（用户此前反馈「变化效果不大」）
