# 孪生站（staging）搭建 · 服务器执行清单

目标：`/opt/comp-agent-staging`，端口 8081，生产 8080 不动，数据隔离。

## 一、复制代码（不含生产数据）

```bash
cp -a /opt/comp-agent /opt/comp-agent-staging
cd /opt/comp-agent-staging
# 数据隔离：清掉生产库和用户数据，让孪生站用独立空库/脱敏副本
rm -f competition.db competition.db-wal competition.db-shm quota.json
rm -rf generated uploads data
mkdir -p generated uploads data
```

说明：`app.py` 的 DB 路径是相对目录 `competition.db`，所以孪生站会自建独立库，**不碰生产数据**。如需真实数据验证，再从生产库导一份脱敏副本单独拷入。

## 二、新 systemd 单元（绑定 8081）

```bash
cat > /etc/systemd/system/comp-agent-staging.service <<'EOF'
[Unit]
Description=科创赛事助手 staging
After=network.target

[Service]
WorkingDirectory=/opt/comp-agent-staging
ExecStart=/opt/comp-agent-staging/.venv/bin/gunicorn -w 1 -b 127.0.0.1:8081 --timeout 300 app:app
Environment=PYTHONIOENCODING=utf-8
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload
systemctl enable --now comp-agent-staging
```

> 若生产不是用 `.venv/bin/gunicorn` 而是别的启动方式，请照抄生产 `comp-agent.service` 的 ExecStart，只把端口改成 8081、目录改成 staging。

## 三、nginx 入口（二选一，优先子域名）

```bash
cat > /etc/nginx/sites-available/comp-agent-staging <<'EOF'
server {
    listen 80;
    server_name staging.kechuang2026.cn;
    location / {
        proxy_pass http://127.0.0.1:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 600;
    }
}
EOF
ln -sf /etc/nginx/sites-available/comp-agent-staging /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
```

> 子域名需要先到 DNS 加一条 `staging.kechuang2026.cn` 的 A 记录指向 `8.149.236.90`（Cloudflare 控制台加）。若来不及配 DNS，临时用 `http://8.149.236.90:8081`（需确认安全组放行 8081）。

## 四、启动自检

```bash
curl -s http://127.0.0.1:8081/api/health
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8081/
```

预期：health 返回 `{success:true,status:ok,...}`，首页 200。

## 五、回执必填

完成后回执写：孪生站访问地址、端口、数据隔离方式（空库/脱敏副本）、`/api/health` 与首页自检结果、双端（桌面+移动）能否打开。

## 六、之后新功能上线流程（长期）

1. 新功能代码先进 `/opt/comp-agent-staging`，`systemctl restart comp-agent-staging`，双端验证全绿。
2. 再 `git fetch` 生产 `/opt/comp-agent` + `safe_restart.sh` 切换生产。
3. 每次切换在共享目录回执写「已上线版本号 + 双端验证结论」。
