# 官方资料：挑战杯（大挑）三类作品

> 用户要求「我要官方的」——所以下面全部是有出处的官方原文，**没有一条是推断的**。
> 出处：挑战杯官方竞赛章程（tiaozhanbei.net/rules）+ 多所高校 2025 年校赛通知互证
> （天津商业大学、洛阳师范学院、江南大学、渤海大学，四份口径一致）。

## 一、官方分类（章程第十九条）

> 申报参赛的作品分为**自然科学类学术论文、哲学社会科学类社会调查报告、科技发明制作**三类。
> 自然科学类学术论文作者限本专科生。
> 哲学社会科学类可围绕经济、政治、文化、社会、生态文明建设等 5 个组别形成社会调查报告。
> 科技发明制作类分为 **A、B 两类**：
> A 类指科技含量较高、制作投入较大的作品；
> B 类指投入较少，且为生产技术或者社会生活带来便利的小发明、小制作等。

注意：哲学社会科学类的组别在近两届有调整，官方口径见过两种——
- 「经济、政治、文化、社会、生态文明建设」5 个组别
- 「发展成就、文明文化、美丽中国、民生福祉、中国之治」5 个组别（第二十届）

**这两套都是官方的，只是届次不同。入库时建议注明届次，或两套都列。**

## 二、三类作品各自的官方要求（差异是硬性的）

### 1. 自然科学类学术论文

- **侧重**（官方）：考核基础学科学术探索的**前沿性和学术性**
- **作品形态**（官方）：参赛作品须为**以学生为第一作者发表的论文**（最少一篇，
  **字数不超 8000 字**），正在投稿的论文、已收到录用通知的论文均可，
  **期刊级别和影响因子是重要参考项**
- **语言**（官方）：论文须为中文，外文论文须有中文翻译
- **写作规范**（官方）：需符合国家标准 **GB 7713-87**（科学技术报告、学位论文和
  学术论文的编写格式）中相关要求和所属学科学术论文一般写作规范
- **支撑材料**（官方）：对论文的进一步阐释、已发表刊物论文页扫描件、影响因子证明、
  查新证明、检索证明、实验相关照片/图片/扫描件
- **提交**（官方）：作品申报书（Word + PDF，参赛论文附在申报书最后页「参赛作品打印处」）+
  支撑材料（PDF）+ 5 分钟路演 PPT

### 2. 哲学社会科学类社会调查报告

- **侧重**（官方）：考核与**经济社会发展热点难点问题的结合程度和前瞻意义**
- **作品形态**（官方）：作品须有**已成型的调查报告**（**15000 字以内**），
  建议有学生为第一作者的论文，或者**政府、企事业单位出具的采纳报告证明**
- **可申报**（官方）：为党政部门、企事业单位所作的各类发展规划、工作方案和咨询报告，
  **已被采用者亦可申报**，同时附上原件和采用单位证明的复印件和鉴定材料
- **支撑材料**（官方）：被采用的发展规划/改革方案/咨询报告、采用单位使用证明、
  **调研过程的问卷、访谈记录、照片**、发表的相关论文、相关单位反馈、奖励证明
- **提交**（官方）：作品申报书（Word + PDF，调研报告附在申报书最后页）+ 支撑材料 + 5 分钟路演 PPT

### 3. 科技发明制作

- **侧重**（官方）：考核作品的**应用价值和转化前景**
- **硬门槛**（官方）：必须是以学生为第一完成人撰写的**发明专利、实用新型专利（最少一项）**，
  也可以是**软件著作权**；正在撰写阶段的专利、拿到受理通知书的专利均可
- **研究报告官方明确要求写出**（这段是官方给的章节结构，可直接当模板用）：
  > 要写出作品制作的**目的意义、制作过程、结果、创新点、实际应用情况（或应用前景）、
  > 存在不足及下一步需要完善的工作**；
  > 报告中需包括**图表、曲线、实验数据、原理结构图、外观图或照片**
- **字数**（官方）：作品说明 **1000 字以内**，研究报告 + 支撑材料 **8000 字以内**
- **学科类别**（官方）：科技发明制作 A、B 两类均设五个学科类别——
  机械与控制、信息技术、数理、生命科学、能源化工
- **实物**（官方，省赛层面）：拟推荐省赛的相关作品**须有实物或模型参展**
- **支撑材料**（官方）：专利、软件著作权、奖项证书、鉴定证书、应用证书、应用证明

## 三、三类通用的官方硬规定

- **公示**（第二十一条）：作品名称、参赛学生、指导教师等关键信息须在**学校官网主页公示
  不少于 5 天**，公示截图随作品一同报送
- **推荐**（第二十二条）：须由 **2 名具有高级职称的指导教师**推荐，
  每件作品不超过 3 名教师指导；**全国竞赛申报后作品题目、作者、指导教师不得变动**
- **不在申报范围**（官方）：毕业设计和课程设计（论文）、学年论文和学位论文、
  国际竞赛获奖作品、获国家级奖励成果
- **字数硬指标汇总**：学术论文 8000 字以内 / 调查报告 15000 字以内 /
  科技发明 作品说明 1000 字以内 + 研究报告 8000 字以内

## 四、建议怎么入库

在 `data/挑战杯.txt` 加：

```
## 赛道设置
(1)自然科学类学术论文：作者限本专科生，考核基础学科学术探索的前沿性和学术性；须为学生第一作者发表的论文（8000字以内），期刊级别和影响因子是重要参考。
(2)哲学社会科学类社会调查报告：考核与经济社会发展热点难点问题的结合程度和前瞻意义；须有成型调查报告（15000字以内），可围绕发展成就、文明文化、美丽中国、民生福祉、中国之治5个组别。
(3)科技发明制作：考核应用价值和转化前景；须有学生为第一完成人的发明专利、实用新型专利或软件著作权；分A类（科技含量高、投入大）与B类（投入少的小发明小制作）。
```

格式要求（前端 `parse_tracks` 的解析规则）：
- 块标题 `## 赛道设置`
- 每行 `(n)名称：说明`，**编号和冒号缺一不可**
- 说明里写官方原文，别自行概括

补完**必须重跑** `python scripts/build_comp_index.py`。

## 五、一条提醒

我现在把「赛道」做成了通用能力，但**只有知识库真写了 `## 赛道设置` 的赛事才显示**。
上面这份是官方原文，可以直接用；但如果某个赛事的赛道划分你只能推断，
**宁可不写**——学生照着推断的赛道填错了，比没有赛道选择更糟。

（前端对非官方内容会打「以下为建议，非官方要求」的标记，`desc` 字段本身必须是官方原文。）
