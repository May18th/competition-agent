# 前端设计守则（前端每次开工前必读）

> 本项目 = 生成表单 + 后台面板，不是营销/落地页。
> 基调：评委视角、克制、**深色科技风**（`--bg-0:#050816`；浅色是 `body.light` 才切的可选主题）。
> 来源：taste-skill 的 `skills/taste-skill/SKILL.md`，仅摘取与本项目相关部分，非全文照搬。

## 必守

1. **配色**：单一强调色（青 `#22d3ee`）+ 单一中性色系，全站锁定，紫/靛只作辅助。
   **渐变与发光只允许出现在两处**：主标题（青→紫→粉，且必须用 `@supports` 包住 fallback）
   与主 CTA 按钮的发光层。其余任何位置出现渐变/发光都算违规 —— 禁的是"满屏渐变 + 处处发光"
   的模板脸，不是禁这两处视觉锚点。
   > 2026-09-28 用户拍板：维持深色科技风。原写的「白底学术、禁 AI 紫/蓝渐变 + 发光按钮」
   > 与线上现状及用户反馈相反，已作废。
2. **形状**：全站一套圆角体系（全方 / 全软 / 全胶囊 三选一），按钮、卡片、输入框不各自为政。
3. **对比度**：按钮与表单文字对背景达 WCAG AA（正文 4.5:1、大字 3:1）；禁白底白字。
4. **三态齐全**：加载、空、错误状态都要真实呈现，不默认转圈/留白。
5. **动效**：可动但要能说明用途；支持 `prefers-reduced-motion` 降级；不加纯装饰无限动画。
6. **移动端**：全高用 `min-height:100dvh` 回落，不写死 `100vh`；flex/grid 子项设 `min-width:0` 防长内容撑破。
7. **长列表**：超过 5 项别用默认 `ul + divide-y` 堆叠，改用下拉/滚动容器等合适组件。

## 补充（output-skill + redesign-skill 蒸馏）

- **完整输出**：不产出占位符 / 空骨架 / 残缺件——禁 `// TODO`、`...`、`待填写`、`【待填写】`、`其余略`，也不用「一个示例 + 以此类推」代替真实内容；要多少就给多少、能跑能看。
- **定点改，不重写**：改现有 `index.html` 前先审计现状，只做针对性修复，不推倒重来。
- **交互三态**：可点击元素要有 hover / active / focus 三态，focus 环可见（键盘可达）。
- **页面主题一致**：浅色页不中途插入纯黑 / 暗色区块；要强调用同色系更深一档，不是突然跳 `#111`。

## 不适用、不要抄

- em-dash 禁令与营销文案那套；
- GSAP / 滚动动画骨架；
- 前端框架选型（Fluent / Carbon / shadcn 等）——本项目单页 `index.html` + 轻 CSS，不引入框架。
