本地 app.js 曾比服务器少 16KB。改 `static/` 或 `index.html` 之前必须先把服务器版本拉下来：

```bash
scp -i ~/.ssh/id_aliyun_deploy root@8.149.236.90:/opt/comp-agent/static/app.js static/app.js
scp -i ~/.ssh/id_aliyun_deploy root@8.149.236.90:/opt/comp-agent/index.html index.html
```

改完上传后**必须同步升 index.html 全站 `v=`**（409 轮规范），否则浏览器吃缓存、改动等于没做。
