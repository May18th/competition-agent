## 二、我这一轮已上线（前端，供你同步）

1. **默认日间浅色**（`7c7b0a8`）：负责人实测「深色背景刺眼」，`initTheme` 默认 `light=true`；用户手动切过夜间（`wbLight='0'`）仍按记忆走深色。浅色变量表本来就有，未动 CSS 结构。
2. **打字机从头到尾就没生效过**（`8330aa8`）：`_STREAM_MAP` 只存在于 app.js 的 IIFE 里、没挂 window，而 `twSet` 在 index.html 的**另一个 script 块**里靠 `_STREAM_MAP` 找 DOM id —— `fieldMeta()` 永远拿到 undefined，`twSet` 每次直接 return。**流式草稿从未渲染过**（生成中看不到内容，结束才整页蹦出来）。已挂 `window._STREAM_MAP`。
3. **闪屏治理**（同一个提交）：`twPaint` 原来每帧 `el.innerHTML = marked.parse(全文)`，深度版 1.2 万字时每秒整段重排约 60 次 —— 用户说的「不稳定要闪屏」就是这么来的。改成**「稳定区 + 尾段」增量渲染**：以空行分界，写完的段落固化不再重绘，只有正在增长的最后一段每帧更新；重绘门槛 8 字 → 24 字；渲染后补偿滚动位置，防止内容变长把视口顶走。带 try/catch 兜底，增量出任何问题回退原文方式。
4. **分享卡片图片**（`8980a5f`）：`og:image` / `og:url` 还指向旧域名（国内打不开），微信/QQ 分享卡片一直无图。已全站切 `https://kechuang2026.cn/`，grep 确认无残留。
5. **评分波动说明**（同上）：用户拍板必做——同一项目两次 74 vs 86，队友以为出 bug。结果页评分大数字下方已常驻「重复生成分数随内容浮动（约 ±10 分），非 Bug；多次生成取最高分版本提交即可」。
6. **footer 文案**（同上）：用户原话「AI 辅助生成，提交前请核对…太掉价」。11 处主标语改为「基于官方评审规则 · AI 多智能体辅助撰写 / 最终内容以你的真实项目与署名为准」。折叠区 3 条详细免责按你要求**一字未动**。
