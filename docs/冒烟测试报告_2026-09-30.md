## 五、总评
【该网站作为比赛作品，登录与核心功能可用：是。】
- 两个授权账号均登录成功；15 个核心页面与 API（前台 SPA、赛事检索、演示案例、答辩FAQ、后台首页/面板/报告/监控、后台统计/审计/知识库、登录态/通用统计）在登录态下全部返回 200。
- 鉴权正确：未登录访问后台返回 401，无越权裸奔。
- 关键写接口（提案生成、AI 对话、赛事匹配、改写润色）路由可达，GET 探针返回 405 证明后端接口已挂载、且本次未执行任何写操作。

【明确不通的点：在只读测试范围内无。】
【局限性说明（重要）】本次为只读冒烟，未实际执行业务写操作。提案生成、AI 对话、导出 PDF/Word、上传解析等"写"类功能仅确认了"路由存在且鉴权/方法正确"（POST-only 返回 405、导出类需 uid cookie），但【未真实验证其生成内容是否正确、是否 500】。这些写链路若要完整验收，需另行授权做一次含写的最小验证（不在本次约束内）。

## 六、所用命令要点（已脱敏，未改动服务器/库/文件）
1. 取 CSRF：`curl -s -c cj.txt -b cj.txt https://kechuang2026.cn/admin/login -o login.html`；提取 `name="csrf" value="..."`。
2. 登录：`curl -s -c cj.txt -b cj.txt -e https://kechuang2026.cn/admin/login -d "username=...&password=123456&csrf=..." https://kechuang2026.cn/admin/login` → 302 即成功。
3. 测 URL：`curl -s -c cj.txt -b cj.txt -o /dev/null -w '%{http_code}' https://kechuang2026.cn/<url>`。
