# 多智能体对标学习架构（科创赛事助手）

> 目标：把"自动去学"升级为「检索学习 → 蒸馏 → 标杆对标 → 差距报告 → 写回改进」的多智能体闭环。
> 所有导出物（申报书/路演PPT/答辩稿/材料模板/图表）持续对标网上高质量获奖作品，且**只学高质量的、不被污染**。

---

## 一、智能体分工

| Agent | 职责 | 输入 | 输出 |
|---|---|---|---|
| 检索学习 Agent | 联网检索高质量获奖提交物与评审口径，过质量门禁 | WebSearch/WebFetch 结果 | 原始素材池 |
| 蒸馏 Agent | 提炼可复用质量标杆（章节/字数/图表/语言/避坑） | 素材池 + 既有 KB | 标杆条目 + 写入 训练库/、docs/ |
| 标杆对标 Agent | 把生成导出物与标杆逐维度对比，打分找差距 | 生成样例 + 标杆 | 差距报告（benchmark_agent.py） |
| 报告 Agent | 汇总本轮增量、对标得分、待修复项、防污染自检 | 各 agent 产出 | 高层报告 |
| 写回/注入 Agent | 把标杆同步进生成器 prompt 与 KB（仅追加） | 标杆 | rich_pipeline/deck_agent/competition_agents 提示词更新 + 云端 push |

---

## 二、闭环流程（每周自动运行）

```
检索学习 ──▶ 蒸馏 ──▶ 标杆对标（对比上轮生成物 vs 标杆）──▶ 差距报告
   │                                      ▲                         │
   │                                      └──── 回看上轮报告确认修复 ┘
   └──────── 写回/注入生成器 prompt + push 云端 ◀── 报告 Agent 汇总
```

1. 检索学习：≥6 来源，质量门禁过滤（官方/获奖复盘/高校双创/权威评委），排除 SEO 软文与模板搬运。
2. 蒸馏：追加进 `训练库/获奖样例蒸馏_vN.json`（标 source+「非原文」+type+score），更新 `docs/*标杆*.md`。
3. 标杆对标：取上轮生成的样例导出物，用 `benchmark_agent.py` 与标杆比，输出 `docs/对标差距报告_YYYYMMDD.md`。
4. 报告：汇总新增样本数、对标得分、待修复项、防污染自检。
5. 写回：把标杆注入生成器 prompt（追加硬约束块），git push 到云端。

---

## 三、防污染铁律（最高优先级）

1. 绝不写入受版权保护的获奖作品原文/他人原文；只写自建原创结构分析，标 source+「非原文」。
2. 绝不编造机构/年份/型号/数据；拿不准标「测算/待补」。
3. `knowledge_base/*.json` 只追加、绝不覆盖服务器未提交的就地蒸馏结果。
4. 每条样本可溯源、可复核；低质量/未核实不入库。
5. 质量门禁：只学高信号来源，排除低信号内容。
6. 有选择地学：优先补弱项赛事/弱项导出物类型。

---

## 四、模块落地

- `benchmark_agent.py`：提供 `build_benchmark_prompt` / `parse_gap_report` / `heuristic_review`，被周任务与未来产品内对标调用。
- `训练库/获奖样例蒸馏_vN.json`：训练样本库（自建原创、过门禁）。
- `docs/路演PPT设计标杆_蒸馏版.md`、`docs/导出物质量标杆_蒸馏版.md`：可机读+人读的标杆。
- 周任务（automation）`科创赛事助手 自动对标学习（联网蒸馏）`：每周一 09:00 自动跑完整闭环。
